## Handoff notes

- Archive navigation path: the sidebar "Archived" control switches the
  existing sidebar into an in-place archive view. "Back to chats" returns to
  the active history list. No new route was added, so the change stays inside
  the task-owned conversation feature paths.
- Undo/attachment cleanup behavior: deleting a conversation still buffers for
  the 5-second undo window. The repository delete removes conversations and
  messages only; attachment metadata and bytes stay in place for the existing
  `AttachmentService.cleanupOrphans` startup path. The new regression test
  verifies rows and bytes survive the undo window, survive commit, and are
  removed by orphan cleanup afterwards.
- Implementation notes: `ConversationService` now exposes
  `setConversationPinned` and `setConversationArchived`, preserving
  `updatedAt`. `useConversationHistory` accepts `showArchived`, filters through
  the repository `archived` option, and sorts pinned conversations first.
  Pinned conversations render in a dedicated "Pinned" group above date groups.
