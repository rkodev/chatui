## Goal

Render assistant and user content safely, including Markdown, GFM, code highlighting, copy, incomplete streaming fences, and message actions.

## Preconditions

- Chat screen and message item extension points exist.
- Add only the dependencies needed for M1 Markdown/code.

## Deliverables

- `react-markdown`, `remark-gfm`, and sanitization dependencies added to `web/package.json`.
- Shiki or an equivalent approved highlighter with a bounded language set and lazy loading.
- Markdown support for headings, lists, tables, blockquotes, task lists, links, inline code, and fenced code.
- Raw HTML rendered as text; links sanitized to http, https, mailto, and in-app anchors.
- External links use `target="_blank"` and `rel="noopener noreferrer"`.
- Remote images blocked by default with a visible placeholder or link.
- Incomplete fenced code during streaming renders as a code block.
- Code block language label and copy exact text.
- Message actions on hover/focus: copy message, copy code, regenerate last assistant, edit last user with truncation confirmation, retry failed.
- Tests for XSS inertness, incomplete fences, link policy, remote images, copy, and truncation confirmation.

## Implementation steps

1. Read `web/package.json` and add only the required dependencies.
2. Build `MarkdownRenderer` with a sanitize schema that does not allow raw HTML.
3. Detect incomplete fences at the end of streaming text and close them for rendering only.
4. Build `CodeBlock` with language label and clipboard copy.
5. Add image rendering policy: do not fetch remote images; render alt text and a blocked indicator.
6. Add action components and wire them to ChatRunner/conversation service.
7. Confirm edit-last-user truncates later messages only after confirmation.
8. Add tests with malicious Markdown and incomplete code.
9. Run lint, typecheck, tests, and build.

## Acceptance criteria

- [ ] GFM constructs render correctly.
- [ ] Raw HTML cannot execute.
- [ ] Links follow the allowlist and external-link attributes.
- [ ] Remote images do not load.
- [ ] Incomplete code fences render as code.
- [ ] Code language label and copy work.
- [ ] Copy, regenerate, edit-last-user, and retry work; no branching is added.
- [ ] Web gate passes.

## Verification

```bash
make web-lint && make web-typecheck && make web-test && make web-build
```

## Out of scope

- Math/KaTeX.
- Attachments and image input.
- Branching, message deletion, or export.
