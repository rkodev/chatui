## Goal

Implement the `CHATUI1\n` backup envelope in a new Rust crate. The codec must
match the shared vectors and must not reuse the `CHUIENC1` secret-file format.

## Preconditions

- `M5-01.1` is `Complete` and the schemas and vectors exist.
- Rust is conditional. If Rust is not shipping, mark this task `Cancelled` with
  the reason and do not block the web/Android gate.
- Do not modify `web/` or `android/`.

## Deliverables

- New crate `rust/crates/chatui-backup/` added to the workspace members.
- `src/envelope.rs` with:
  - `MAGIC: &[u8] = b"CHATUI1\n"`.
  - `EnvelopeHeader` serde struct with `v`, `formatVersion`, `alg`, `kdf`,
    `iterations`, `salt`, `objectType`, `objectKey`.
  - `encode_envelope`/`decode_envelope`.
  - `encrypt_object`/`decrypt_object` with optional gzip.
  - AAD construction from `objectType` and `objectKey`.
- `src/error.rs` with typed errors for bad magic, bad header, auth failure, and
  unsupported version.
- `src/lib.rs` re-exports.
- Tests:
  - Round trip for manifest, conversation, and attachment.
  - Shared vector comparison.
  - Fresh IV per write.
  - Wrong passphrase fails.
  - Tampered magic, header, IV, ciphertext, and AAD fail.
  - Gzip round trip and attachment no-gzip.
  - Unknown `v`/`formatVersion` handling.

## Implementation steps

1. Read `rust/crates/chatui-secrets/src/encrypted_file.rs` for patterns, but do
   not reuse its magic or format.
2. Create the crate and add it to `rust/Cargo.toml` members.
3. Add dependencies: `aes-gcm`, `pbkdf2`, `sha2`, `rand`, `serde`,
   `serde_json`, `base64`, `flate2`, `thiserror`, `zeroize`.
4. Implement the byte layout exactly as frozen:
   - magic 8 bytes, big-endian `u32` header length, UTF-8 header JSON,
     12-byte IV, ciphertext with the 16-byte tag appended.
5. Derive the key with PBKDF2-HMAC-SHA256, 600,000 iterations, 16-byte salt,
   32-byte key.
6. Build AAD from `objectType` and `objectKey` exactly as frozen.
7. Implement optional gzip with `flate2`. Never gzip attachment bytes.
8. Add a passphrase verification token helper consistent with the other clients.
9. Add tests using the shared vectors and synthetic data only.
10. Run the Rust gates and fix failures.

## Acceptance criteria

- [x] The crate builds and is a workspace member.
- [x] Envelope encode/decode matches the frozen byte layout.
- [x] Header JSON contains every required field.
- [x] AAD binds `objectType` and `objectKey`; tampering fails.
- [x] A fresh 12-byte IV is used for every write.
- [x] PBKDF2 uses 600,000 iterations, 16-byte salt, and a 32-byte key.
- [x] Conversation payloads are gzipped; attachment bytes are not.
- [x] Wrong passphrase and tampered ciphertext fail safely.
- [x] Shared vectors pass.
- [x] The `CHUIENC1` secret-file format is unchanged.
