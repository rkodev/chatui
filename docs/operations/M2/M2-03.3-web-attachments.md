## Goal

Deliver the complete web attachment flow from input to provider-specific content parts.

## Preconditions

- Web attachment byte store and metadata repository exist.
- Provider adapters support or reject attachments through shared capability helpers.

## Deliverables

- File picker, drag-and-drop, and clipboard image paste.
- Type and size validation for images and text files.
- Image downscale to 2048 px longest edge, re-encode where appropriate, and metadata stripping.
- Content-addressed storage and transactional metadata persistence.
- Composer chips/thumbnails, removal before send, and message rendering after send.
- Provider-specific content parts: OpenAI data URLs, Anthropic base64 blocks, Gemini `inlineData`, and text-file headers.
- Capability warnings and confirmation when switching to a text-only model with attachments.
- Reload, orphan cleanup, and invalid-file tests.

## Implementation steps

1. Read the existing `AttachmentStore`, `AttachmentRepository`, `Composer`, and `chatRequest.ts`.
2. Add the attachment service that validates, processes, hashes, and stores files.
3. Add picker, drag/drop, and clipboard paste inputs.
4. Add downscale/re-encode and metadata stripping.
5. Persist metadata transactionally and render chips/messages.
6. Extend request construction to provider-specific content parts.
7. Add capability warnings and model-switch confirmation.
8. Wire cleanup for removed/edited/deleted attachments.
9. Add tests for input, processing, persistence, reload, and request serialization.
10. Run web gates.

## Acceptance criteria

- [ ] Images and supported text files can be added by picker, drop, and paste.
- [ ] Invalid types/sizes are rejected without corrupting state.
- [ ] Images are downscaled and metadata is stripped.
- [ ] Attachment bytes stay local and survive reload.
- [ ] Provider-specific content parts match request vectors.
- [ ] Unsupported attachments warn before send/model switch.
- [ ] Removed/deleted attachments are cleaned up.
- [ ] Web gates pass.

## Verification

```bash
make web-lint && make web-typecheck && make web-test && make web-build
```

Plus manual picker, paste, drop, and reload checks.

## Out of scope

- Android attachments.
- Attachment export/import implementation.
- Remote provider file upload beyond inline content parts.
