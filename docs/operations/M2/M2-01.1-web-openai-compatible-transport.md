## Goal

Extract a preset-driven OpenAI-compatible transport from the OpenRouter implementation while preserving OpenRouter behavior exactly.

## Preconditions

- M2-00.2 expected vectors and request vectors are complete.
- Do not add Custom provider UI in this task.

## Deliverables

- One adapter surface for key validation, model discovery, and chat streaming parameterized by a provider preset.
- Preset-driven base URL, auth headers, attribution headers, default headers, and model-discovery format.
- Request builder that uses the shared request vectors.
- Error, retry, cancellation, and SSE behavior that preserves M1 OpenRouter semantics.
- Preset runtime context that carries only the provider id, base URL, auth type, headers, and API key.
- Tests for OpenAI-compatible text, usage, errors, retry, cancellation, and protected fields.
- OpenRouter regression suite remains green.

## Implementation steps

1. Read the existing `openrouter.ts`, `openrouterStream.ts`, `sse.ts`, and `retry.ts`.
2. Introduce a generic OpenAI-compatible transport without changing normalized event shapes.
3. Move OpenRouter-specific behavior behind a preset/adaptor configuration object.
4. Keep attribution header behavior only where the preset declares attribution headers.
5. Build request bodies from the shared request vectors and the model's supported parameters.
6. Preserve OpenRouter in-stream error handling, reasoning deduplication, and usage mapping.
7. Add adapter tests against OpenAI fixtures and rerun OpenRouter tests.
8. Run web gates.

## Acceptance criteria

- [ ] The OpenAI-compatible transport is preset-driven, not OpenRouter-named.
- [ ] OpenRouter behavior and tests are unchanged.
- [ ] OpenAI text, usage, retry, cancellation, and error fixtures pass.
- [ ] Protected fields cannot be overridden.
- [ ] The adapter never logs or places keys in URLs.
- [ ] No native adapters or attachment UI are added.
- [ ] `make web-lint && make web-typecheck && make web-test && make web-build` passes.

## Verification

```bash
make web-lint && make web-typecheck && make web-test && make web-build
```

## Out of scope

- Enabling additional presets or Custom provider creation.
- Anthropic, Gemini, and Ollama.
- Attachments, parameters UI, search, export/import, and Playwright.
