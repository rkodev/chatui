## Goal

Add CI workflows that prove contracts and the web foundation pass on pull requests.

## Preconditions

- Contracts validate locally.
- Web lint, typecheck, tests, and build pass locally.
- `web/pnpm-lock.yaml` is committed.

## Deliverables

- `.github/workflows/contracts.yml`:
  - triggers on pull requests and pushes to the default branch
  - Node LTS setup
  - `npm ci --prefix scripts`
  - `make contracts-check` or `node scripts/validate-contracts.mjs`
  - `permissions: contents: read`
  - concurrency group per branch/PR with cancel-in-progress
  - bounded timeout
- `.github/workflows/web.yml`:
  - triggers on pull requests and pushes to the default branch
  - pnpm setup with the pinned version
  - Node LTS setup with pnpm cache keyed by `web/pnpm-lock.yaml`
  - `npm ci --prefix scripts` and contracts check
  - `pnpm install --frozen-lockfile`
  - `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`
  - upload `web/dist` as an artifact with bounded retention
  - `permissions: contents: read`
  - concurrency and timeout
- No secret echoing, release signing, container publishing, or deployment.
- Remove `.github/workflows/.gitkeep` when workflows exist.

## Implementation steps

1. Write `contracts.yml` and validate it locally if actionlint is available.
2. Write `web.yml`.
3. Confirm the workflow commands match the actual package scripts and lockfile.
4. Push a draft PR or use the repository's CI mechanism to run both workflows.
5. Fix any CI-only failures, such as a missing install step or pnpm cache path.
6. Record workflow run links or results in the handoff notes.

- Web uploads `web/dist` as `web-dist` with 7-day retention and fails if the directory is missing.
- No secrets, signing, publishing, deployment, or secret echoing.
