# M0-05.1 - Android design system and theme

- Status: Not started
- Parent task: M0-05
- Order: 18
- Depends on: M0-04.4
- Parallel-safe: yes, with M0-03.3
- Owns: `android/core/designsystem/**`, its module build file, corresponding tests
- Read first: [M0 plan](../M0-foundations-implementation-plan.md) sections 3.3 and 4.6; spec sections 3.8, 11.11, 11.12

## Goal

Implement the Material 3 design system so the app can render a themed shell with the shared semantic tokens.

## Preconditions

- The `core:designsystem` module exists and builds.
- No feature UI is allowed.

## Deliverables

- Material 3 color schemes for light and dark themes.
- System theme support via `isSystemInDarkTheme()` or an equivalent setting.
- Semantic tokens from spec 11.12 mapped to Compose values:
  - background, surface, raised surface, user bubble, code background
  - foreground primary, secondary, muted, on-accent
  - accent, accent-hover, subtle and strong borders
  - danger, warning, success
  - spacing, radii, body/code typography, heading styles
- `Dimens` and `Typography` objects with semantic names matching the web token names.
- Density support for comfortable and compact modes.
- Reduced-motion support where Compose exposes animation duration or motion preferences.
- A `ChatUiTheme` composable that accepts theme mode and density.
- Tests or compile-time checks for theme construction and token availability.

## Implementation steps

1. Translate the token list into Compose objects.
2. Build light and dark color schemes.
3. Add typography and dimens.
4. Add the theme composable and density handling.
5. Add reduced-motion handling.
6. Run the module build and Android gates.

## Acceptance criteria

- [ ] Light, dark, and system themes exist.
- [ ] All semantic token names from spec 11.12 are represented or intentionally mapped.
- [ ] Comfortable and compact density exist.
- [ ] Reduced-motion behavior is respected where applicable.
- [ ] No feature screen is included.
- [ ] `:app:assembleDebug`, `:app:testDebugUnitTest`, and `:app:lintDebug` pass.

## Verification

```bash
cd android && ./gradlew :core:designsystem:assembleDebug
cd android && ./gradlew :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

## Out of scope

- Dynamic color configuration UI, screenshot tests, and full accessibility audit.
- Feature-specific components and screens.
