## Goal

Implement Android OpenRouter `GET /key` and `GET /models` with the same mapping and cache semantics as web.

## Preconditions

- Registry and OkHttp client are available.
- Do not implement chat streaming in this task.

## Deliverables

- `validateKey(context)` returning `ProviderKeyInfo`.
- `listModels(context)` returning `ModelInfo`.
- Catalog mapping for IDs, canonical slug, label, context, max output, modalities, pricing per million, supported parameters, free flag, and metadata.
- Decimal-safe price conversion and raw pricing preservation.
- 24-hour cache, manual refresh, and last-known-good snapshot.
- Attribution headers from app config.
- MockWebServer/fixture tests for paid, free, vision, reasoning, tool, long-context, unusual pricing, unknown fields, and cache failures.

## Implementation steps

1. Reuse the mapping decisions from web to avoid divergence.
2. Implement `/key` request with bearer auth and attribution headers.
3. Map key metadata exactly as spec 7.4 lists.
4. Implement `/models` request and parse the raw envelope.
5. Map every catalog field and ignore unknown fields.
6. Implement cache storage using an injectable cache interface so JVM tests do not need app storage.
7. Return last-known-good on refresh failure with an error flag.
8. Add MockWebServer tests for success and failure.
9. Ensure keys never appear in logs or errors.

### Cache abstraction

`CatalogCache` is a suspend interface with `read(key)` and `write(key,
snapshot)`. `MemoryCatalogCache` is the default and clones snapshots on read
and write. `OpenRouterAdapter` accepts an injected cache and clock, so JVM
tests never need app storage. Cache read failures are treated as misses and
cache write failures are ignored after a successful refresh. The cache key is
`chatui.catalog.<providerId>.v1`.

### Price helper

`multiplyDecimalByMillion(value)` shifts the decimal point six places using
string arithmetic and returns a canonical decimal string. `usdPerMillion`
wraps it for `pricing.prompt` and `pricing.completion`. `usdAmount` parses
`pricing.request` without multiplying. Raw pricing strings are preserved under
`metadata.pricing`.

### Fixture loading

Tests read the shared fixtures from the test classpath at
`/contracts/fixtures/models/openrouter-models.json` and
`/contracts/fixtures/models/openrouter-key.json`. The existing
`syncContractTestResources` Gradle task copies `contracts/fixtures` into the
test resources, so no fixture duplication was needed.

### API notes for downstream tasks

- `OpenRouterAdapter` does not implement `ProviderAdapter` yet because
  `streamChat` belongs to M1-06.4. M1-06.4 should add `streamChat` and then
  implement the interface.
- `listModels` returns `List<ModelInfo>` for adapter compatibility. Use
  `loadCatalog` when the caller needs `fromCache`, `stale`, and `refreshError`
  flags; `refreshCatalog` forces a refresh while preserving last-known-good.
- `OpenRouterAttribution` is supplied through the adapter constructor rather
  than `ProviderContext`, so no shared context type was widened for
  attribution.
- The key is sent only in the `Authorization` header and never in a URL. Error
  messages are redacted before they reach the caller.
