## Goal

Implement a provider-agnostic SSE transport that matches the shared fixtures and never parses provider JSON.

## Preconditions

- Domain and conformance scaffold exist.
- Do not parse provider payloads in this module. The adapter owns JSON.
- Do not use an unbounded buffer.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- A bounded SSE reader over an async byte stream.
- CRLF, LF, and lone-CR normalization, including a CR split across chunks.
- Event separation by a blank line.
- Multi-line `data:` concatenation.
- Comment/keep-alive tolerance.
- Final event flush when the stream ends without a trailing blank line.
- Abort/cancellation support.
- A configurable maximum buffer size with a clear overflow error.
- Tests against every raw stream fixture and property tests for chunk boundaries.

## Implementation steps

1. Read `web/src/providers/sse.ts` and spec appendix 21.1.
2. Define an async API such as `read_sse(stream, on_event, cancel, max_buffer)`.
3. Normalize line endings before splitting. Hold a trailing `\r` until the next chunk so CRLF split across chunks is handled.
4. Accumulate only `data:` fields. Ignore comments beginning with `:` and unknown fields.
5. Join multiple `data:` lines with `\n`.
6. Emit only non-empty data values. Keep-alive comments must not produce events.
7. Flush the final event when the stream ends.
8. Enforce a maximum incomplete-event buffer. Return a typed overflow error, never an unbounded allocation.
9. Support cancellation promptly. Do not read further after cancellation.
10. Add tests that feed every fixture through the parser and compare the raw `data:` event sequence. Do not parse JSON in the parser.
11. Add property tests or chunk-boundary tests for CRLF splits, lone CR, multi-line data, empty data, comments, and overflow.

## Acceptance criteria

- [ ] The parser handles CRLF, LF, and lone CR.
- [ ] Multi-line data is joined with a single newline.
- [ ] Comments and keep-alives are ignored without producing events.
- [ ] The final event flushes at end of stream.
- [ ] The buffer is bounded and overflow is a typed error.
- [ ] Cancellation stops reading promptly.
- [ ] No JSON parsing exists in the SSE module.
- [ ] Fixture and property tests pass.
