## Goal

Render assistant and user content safely, including Markdown, GFM, code highlighting, copy, incomplete streaming fences, and message actions.

## Preconditions

- Chat screen and message item extension points exist.
- Add only the dependencies needed for M1 Markdown/code.

## Deliverables

- `react-markdown`, `remark-gfm`, and sanitization dependencies added to `web/package.json`.
- Shiki or an equivalent approved highlighter with a bounded language set and lazy loading.
- Markdown support for headings, lists, tables, blockquotes, task lists, links, inline code, and fenced code.
- Raw HTML rendered as text; links sanitized to http, https, mailto, and in-app anchors.
- External links use `target="_blank"` and `rel="noopener noreferrer"`.
- Remote images blocked by default with a visible placeholder or link.
- Incomplete fenced code during streaming renders as a code block.
- Code block language label and copy exact text.
- Message actions on hover/focus: copy message, copy code, regenerate last assistant, edit last user with truncation confirmation, retry failed.
- Tests for XSS inertness, incomplete fences, link policy, remote images, copy, and truncation confirmation.

## Implementation steps

1. Read `web/package.json` and add only the required dependencies.
2. Build `MarkdownRenderer` with a sanitize schema that does not allow raw HTML.
3. Detect incomplete fences at the end of streaming text and close them for rendering only.
4. Build `CodeBlock` with language label and clipboard copy.
5. Add image rendering policy: do not fetch remote images; render alt text and a blocked indicator.
6. Add action components and wire them to ChatRunner/conversation service.
7. Confirm edit-last-user truncates later messages only after confirmation.
8. Add tests with malicious Markdown and incomplete code.
9. Run lint, typecheck, tests, and build.

## Handoff notes

- Sanitize schema: `MARKDOWN_SANITIZE_SCHEMA = { ...defaultSchema, protocols: { ...defaultSchema.protocols, href: ['http', 'https', 'mailto'] } }`. Raw HTML is converted to text before sanitization so it stays visible but inert. The `urlTransform` returns an empty string for rejected URLs, and custom `a`/`img` components render rejected content as non-links or blocked placeholders.
- Link policy: absolute `http`, `https`, and `mailto` URLs plus in-app `#anchor` links are allowed. External links get `target="_blank"` and `rel="noopener noreferrer"`; anchors do not.
- Highlighter language set: `bash`, `c`, `cpp`, `csharp`, `css`, `diff`, `go`, `html`, `java`, `javascript`, `json`, `jsx`, `kotlin`, `markdown`, `php`, `python`, `ruby`, `rust`, `shellscript`, `sql`, `swift`, `toml`, `tsx`, `typescript`, `xml`, `yaml`. `normalizeLanguage` maps common aliases such as `js`, `ts`, `py`, `sh`, `yml`, and `c++`; unknown languages render as plain text with the original label.
- Copy behavior: code blocks copy the exact source text (only the trailing newline added by Markdown parsing is removed). Message copy joins all text parts with a blank line (`\n\n`). Both use the async Clipboard API with a hidden-textarea `execCommand` fallback and show `Copied` for 1.5 seconds.
- Actions: copy is always available; regenerate appears only on the last assistant message, and edit appears only on the last user message. Both are hidden on hover/focus and always visible on touch devices. Edit opens a dialog that warns every later message will be deleted before `ChatService.editLastUser` runs.
- Truncation semantics: `MessageRepository.truncateAfter(conversationId, sequence)` deletes messages with a strictly greater sequence in one transaction and updates `messageCount`, `lastMessageAt`, and `updatedAt`. The caller rewrites the target and appends the replacement assistant response.
- Test coverage: `MarkdownRenderer.test.tsx` covers GFM, XSS inertness, the link allowlist, blocked remote images, and incomplete fences; `CodeBlock.test.tsx` covers labels, exact copy, wrapping, and inline code; `MessageActions.test.tsx` covers copy, regenerate gating, and edit confirmation/cancel; `chatService.test.ts` covers edit truncation and resend.
