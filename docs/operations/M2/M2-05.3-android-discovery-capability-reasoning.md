## Goal

Make discovery, fallback models, capability inference, and reasoning usable for every enabled OpenAI-compatible preset on Android.

## Preconditions

- M2-05.2 preset enablement is complete.
- Expected catalog vectors exist.

## Deliverables

- Per-preset discovery using the preset's path and format.
- Per-preset cache keys, TTL, forced refresh, and last-known-good.
- Fallback model selection when discovery is blocked.
- Capability inference for missing modalities, capabilities, context, and supported params.
- Reasoning normalization for OpenAI-compatible streams.
- Tests for catalog mapping, discovery failure, fallback, capabilities, and reasoning.

## Implementation steps

1. Read `ModelService`, `ProviderGateway`, and the OpenRouter catalog mapper.
2. Generalize discovery by preset format while preserving OpenRouter cache behavior.
3. Add fallback model selection.
4. Add capability inference at the catalog-to-model boundary.
5. Normalize `reasoning_content` and other supported reasoning fields.
6. Add tests for discovery failure and missing metadata.
7. Run Android gates.

## Acceptance criteria

- [ ] Discovery works for every enabled OpenAI-compatible preset in tests.
- [ ] Blocked discovery yields fallback models and a warning.
- [ ] Missing modalities/capabilities are inferred.
- [ ] Reasoning appears separately and is not replayed.
- [ ] OpenRouter catalog/free badge behavior is unchanged.
- [ ] Android gates pass.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```

## Out of scope

- Native adapters.
- Provider UI and shell wiring.
- Attachment capability warnings.
