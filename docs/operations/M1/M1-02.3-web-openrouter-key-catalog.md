## Goal

Implement OpenRouter `GET /key` and `GET /models` with normalized catalog mapping, a 24-hour cache, manual refresh, and last-known-good behavior.

## Preconditions

- M1-02.1 registry is available.
- Do not implement `POST /chat/completions` in this task.

## Deliverables

- `validateKey(context, signal)` returning `ProviderKeyInfo`.
- `listModels(context, signal)` returning normalized `ModelInfo`.
- Mapping for `id`, `canonical_slug`, `name`, `context_length`, `top_provider.*`, `architecture.*`, `pricing.*`, `supported_parameters`, `default_parameters`, `per_request_limits`, and unknown non-secret metadata.
- Price conversion from USD per token to USD per million, preserving raw strings in metadata.
- Free-model detection using zero effective pricing and the `:free` suffix.
- Capability inference for text, vision, files, tools, reasoning, and streaming.
- Catalog cache with 24-hour TTL, manual refresh, and last-known-good snapshot on failure.
- Attribution headers from runtime config.
- Tests against `contracts/fixtures/models/openrouter-models.json`, `openrouter-key.json`, and synthetic malformed responses.

## Implementation steps

1. Read the catalog mapping table in spec 7.4 twice; implement it field by field.
2. Use decimal-safe conversion for price strings. Do not parse binary floats directly for per-million display.
3. Treat unknown fields as ignorable and copy only small non-secret values into metadata.
4. Implement cache read/write. Store `fetchedAt` and the last successful normalized catalog.
5. On network or parse failure, return the last-known-good catalog with a refresh error flag.
6. Implement key validation mapping including `label`, usage, limit, free-tier, and rate limit.
7. Ensure the API key is never placed in a URL or log.
8. Add fixture tests for paid, free, vision, reasoning, tool, long-context, unusual pricing, and unknown-field models.
9. Add tests for cache hit, expiry, refresh, and failure fallback.

### Cache storage key

`openRouterCatalogCacheKey(providerId = 'openrouter')` returns
`chatui.catalog.<providerId>.v1`, so the OpenRouter key is
`chatui.catalog.openrouter.v1`. The default cache is `localStorage`-backed;
tests and callers can inject any `CatalogCache`. A snapshot stores
`{ fetchedAt: number, models: ModelInfo[] }`. Cache read/write failures are
treated as misses or ignored so discovery still succeeds.

### Price-conversion helper

`multiplyDecimalByMillion(value: string)` shifts the decimal point six places
using string arithmetic and returns a canonical decimal string. `usdPerMillion`
wraps it for `pricing.prompt` and `pricing.completion`. `usdAmount` parses
`pricing.request` without multiplying. Raw pricing strings are preserved under
`metadata.pricing`.

### `top_provider` fallback

`contextWindow` prefers the top-level `context_length`, then
`top_provider.context_length`. `maxOutputTokens` prefers
`top_provider.max_completion_tokens`, then falls back to the resolved
`contextWindow`. Missing or non-positive values become `null`.

### API notes for downstream tasks

- `listModels` returns `ModelInfo[]` for adapter compatibility. Use
  `loadCatalog` when the caller needs `fromCache`, `stale`, and `refreshError`
  flags; `refreshCatalog` forces a refresh while preserving last-known-good.
- `ProviderContext` is `{ provider: Pick<Provider, 'id' | 'baseUrl'>, apiKey,
  fetch, attribution? }`. `attribution` is `{ origin, title }` from runtime
  config. The key is sent only in the `Authorization` header and never in a
  URL.
- `ModelInfo` adds `isFree` beyond the Android shape so the UI can show a Free
  badge without re-parsing pricing. `ProviderKeyInfo` adds
  `limitRemainingUsd` to match the shared expected key vector.
- `web/src/providers/index.ts` was not changed because it is outside this
  task's `Owns` list. Downstream code can import from
  `web/src/providers/openrouter` and `web/src/providers/openrouterCatalog`
  directly.
