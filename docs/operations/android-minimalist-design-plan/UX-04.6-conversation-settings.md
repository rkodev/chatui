# UX-04.6 - Conversation essentials and generation

- Phase: UX-04 - Setup, providers, and models
- Status: Blocked
- Order: 25
- Depends on: UX-04.1
- Output folder: `docs\operations\android-minimalist-design-plan`
- Parallel-safe: No with conversation settings/picker-host callback edits.

## Goal

Lead conversation settings with Model/System prompt, use the full picker, and
group generation overrides without changing immediate per-chat persistence.

## Read first

Read the [execution contract](README.md), source-plan section 5.4,
`Providers\ConversationSettingsRoute.kt`,
`Providers\ConversationSettingsSheet.kt`,
`Providers\ConversationSettingsViewModel.kt`, UX-02.4's host contract,
and conversation settings/parameter/snapshot/sheet tests.

## Owns

The three listed conversation-settings files, app-owned picker callback/
result wiring in the shell, and focused settings/route/sheet tests.
Keep advanced JSON content working for UX-04.7.

## Deliverables

Model/System prompt essentials, a summarized Generation disclosure, exact
numeric/default controls, and integrated per-conversation picker behavior.

## Implementation steps

1. Put Model and System prompt first. Replace the unsearchable model dropdown
   with the app callback to `ModelPickerTarget.Conversation(conversationId)`.
2. Coordinate parent settings/child picker presentation with the shell so
   Back closes only the top layer and dismissal returns focus/state to settings.
   Refresh from the persisted selection rather than keeping stale VM snapshots.
3. Put temperature, Top P, max output tokens, stop sequences, reasoning effort,
   and streaming under Generation. Summarize active overrides when collapsed.
4. Preserve exact numeric input and the distinction between unset/model
   default and an explicit value. If retaining/adding sliders, keep the exact
   input and reset-to-default semantics; do not clamp supported values silently.
5. Preserve immediate persistence, system prompt/parameter retention after
   model change, unsupported-parameter notes, and historical model snapshots.
   Do not add a Save button implying staged settings.
6. Keep Advanced/extras reachable unchanged for UX-04.7. Move no working share
   actions out of More; keep Delete at the bottom with its exact confirmation.
   A disabled future export control must not resemble a working primary action.
7. Add cases for every generation field/default reset, picker target/return,
   model-change retention, collapsed summaries, delete cancel/confirm,
   large-font/IME layout, and one-layer Back.
