## Handoff notes

- Adapter registration: `GeminiAdapter` implements `CatalogAdapter`.
  `ProviderAdapterRegistry` maps `ProviderKind.GOOGLE_GEMINI` to it, and
  `RoutingProviderAdapter` / `RoutingProviderGateway` dispatch by
  `context.provider.kind`. `google` is enabled in `M2_ENABLED_PRESET_IDS`, so
  the provider UI can create and validate Gemini providers.
- URLs: discovery uses `GET {baseUrl}/models`; chat uses
  `POST {baseUrl}/models/{model}:streamGenerateContent?alt=sse`. The model id
  has any `models/` prefix removed and is URL-encoded. The key is sent only in
  `x-goog-api-key` and never appears in a URL.
- Request body: `contents` uses `model` for assistant turns and `user`
  otherwise. The system prompt is a top-level `systemInstruction`. Images
  serialize as `inlineData` with `mimeType` and base64 `data`; text files
  decode to a `[File: name]` text part. Advanced JSON under
  `params.extra.google` cannot override `model`, `messages`, `stream`, or
  `stream_options`.
- Stream mapping: `usageMetadata.promptTokenCount` / `candidatesTokenCount` /
  `totalTokenCount` map to `Usage`. `STOP` maps to `stop`, `MAX_TOKENS` to
  `length`, and `SAFETY`/`RECITATION` to `content_filter`. The contract fixture
  orders `finish` before `usage`, so usage is flushed at finish time. Parts with
  `thought: true` map to `reasoning-delta`.
- Error mapping: HTTP 400 API-key messages map to `auth`, context messages to
  `context_length`, 403 to `permission` unless moderation-related, 404 to
  `model_not_found`, 429 to `rate_limit` with `Retry-After`, and 5xx to
  retryable `provider`. In-stream `error` envelopes map by `code` or `status`
  with `retryable = false`.
- Deferred cases: `ModelService.refreshModels` still passes no API key to
  discovery, so Gemini discovery falls back to the shared fallback models until
  secret plumbing is added to the model service. Ollama remains disabled.
