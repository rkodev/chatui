Known M2 deferrals and residual risks that affect the Rust track:

| Item | Relevance to Rust |
| --- | --- |
| Android local Ollama over cleartext HTTP lacks a network security config | Rust must implement its own localhost/private-range cleartext policy; do not copy the Android gap. |
| Android Anthropic and Gemini discovery runs without a key and falls back to shared lists | Rust discovery must pass the key where the provider requires it and record any fallback honestly. |
| Android math typesetting uses bounded raw source | Rust may use a sanitized raw-source fallback first; typesetting only if proven safe. |
| Android device-level input and visual checks are unit/Compose only | Rust needs its own OS smoke and accessibility evidence. |
| Web case 23 (10,000-message windowing) has no automated test | Rust must provide its own windowing test/evidence. |
| Live provider smoke and valid-key success were not re-run for every cloud preset | Rust conformance must rely on shared fixtures and mocks; live smoke remains a release check. |
| Local and Custom CORS remain `unknown` | CORS is irrelevant to desktop transport, but `browserCors` must still round-trip for contract/export compatibility. |
