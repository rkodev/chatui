## Goal

Deliver the Android conversation list/drawer, creation, rename, delete, date grouping, last-active restore, and navigation to chat.

## Preconditions

- Repositories and provider/model UI exist.
- Do not implement the chat screen in this task.

## Deliverables

- Conversation list/drawer with New chat and date groups: Today, Yesterday, Previous 7 days, Previous 30 days, Older.
- Conversation item with title, timestamp, and rename/delete actions.
- Delete confirmation. Undo is optional; if omitted, record why.
- Safe new-chat behavior using defaults.
- Last-active conversation restore.
- Navigation from shell and conversation list to the chat route.
- Tests for grouping, create, rename, delete, and restore.

## Implementation steps

1. Read the conversation placeholder, repository APIs, and shell navigation.
2. Build a conversation list ViewModel with grouped state.
3. Build the drawer/list composable with Material 3 components.
4. Implement new chat, rename, and delete with confirmation.
5. Wire last-active tracking through settings.
6. Add a chat destination that accepts a conversation ID.
7. Update the shell start behavior to onboarding or last active chat.
8. Add tests and run the Android gate.

## Acceptance criteria

- [ ] Date groups match the required buckets.
- [ ] New chat, rename, and delete work and persist.
- [ ] Last-active conversation restores after relaunch.
- [ ] Navigation reaches the chat destination with a conversation ID.
- [ ] Search, pin, and archive are not added.
- [ ] Android gate passes.

make android-lint && make android-test && make android-assemble
