## Goal

Run the required device matrix and record real results, including blockers.

## Preconditions

- M3-05.4 tests and M3-06.4 release artifacts exist.
- Share/deep-link work is complete.
- Use the signed release or a debug build that differs only in signing/minification; record which.
- Use disposable test data only.

## Deliverables

- A completed matrix for Android 8, 12, 14, current, one low-RAM device, and one tablet.
- Results for:
  - onboarding and key entry;
  - chat send/stream/stop;
  - photo picker and SAF document picker;
  - clipboard image paste;
  - drag-and-drop on tablet/ChromeOS where available;
  - share target and deep links;
  - predictive back and shortcuts where applicable;
  - process-death behavior;
  - backup exclusion where the device supports it;
  - adaptive layout and insets.
- A release-blocker list with owners.

## Implementation steps

1. Read the matrix template in the M3 plan section 6.3 and the environment notes from M3-00.1.
2. Use physical devices where available. If only emulators are available, record the model/API and state that clearly.
3. Install the release or documented debug build on each target.
4. Run every matrix item and record pass/fail/blocked with a short note.
5. For process death and backup, use the procedures from M3-04.4 and M3-01.2.
6. For local providers, use a disposable local server and the cleartext policy from M3-01.4.
7. Record screenshots only when they contain no keys or personal data.
8. Add the completed matrix to `M3-verification.md`.
9. List any release-blocking issue with an owner and next action. Do not mark the matrix pass if a blocker remains.

## Acceptance criteria

- [x] Every required Android version/form factor has a recorded result.
- [x] Every platform item in the list above has evidence or a recorded limitation.
- [x] Process death and backup evidence are linked.
- [x] Environment limitations are stated, not hidden.
- [x] Release blockers are listed with owners.
- [x] No real key, prompt, or personal data is recorded.

## Verification

Manual execution of the matrix plus:

```bash
make android-lint && make android-test && make android-assemble
```

## Out of scope

- Fixing device-specific defects; file follow-up tasks.
- M4 cross-platform audit.
- Play Store testing tracks.
