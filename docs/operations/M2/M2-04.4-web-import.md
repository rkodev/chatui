## Goal

Implement safe `chatui.export` import with schema validation, size limits, merge-by-default, and no mutation on invalid input.

## Preconditions

- M2-04.3 export produces schema-valid archives.
- Shared export fixture exists.

## Deliverables

- File import UI and service.
- Schema, size, ID, path, and attachment-name validation.
- Merge-by-default behavior and optional replace mode.
- Transactional application of valid archives.
- No local mutation on invalid or partial input.
- Preservation of IDs, ordering, snapshots, and attachment references.
- Tests for valid round trip, invalid schema, oversized input, duplicate IDs, unsafe paths, and replace/merge.

## Implementation steps

1. Read the export schema, fixture, and import expectations.
2. Add input size and schema validation before any write.
3. Validate IDs, conversation/message relationships, provider/model references, and attachment names.
4. Implement transactional merge-by-default.
5. Add optional replace mode with confirmation.
6. Restore attachment metadata and optional bytes.
7. Add tests for every invalid-input class and the round trip.
8. Run web gates.

## Acceptance criteria

- [ ] Valid archives import and round trip.
- [ ] Merge is the default and does not duplicate records.
- [ ] Replace mode is explicit and confirmed.
- [ ] Invalid imports do not mutate local data.
- [ ] Unsafe paths or attachment names are rejected.
- [ ] IDs, ordering, snapshots, and attachments are preserved.
- [ ] Web gates pass.
