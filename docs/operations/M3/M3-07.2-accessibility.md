## Goal

Verify the Android accessibility baseline and fix small, test-covered issues without starting the M4 cross-platform audit.

## Preconditions

- M3-05.3 screenshot coverage and M3-03.4 shell work are complete.
- Do not add translations or dynamic-color behavior unless M3-00.2 explicitly asks.
- Do not rewrite screens for accessibility beyond small fixes.

## Deliverables

- A recorded semantics/content-description audit for interactive elements.
- A 48 dp touch-target audit.
- TalkBack notes for onboarding, chat send/stream, model picker, providers, settings, and error states.
- Reduced-motion verification.
- Dynamic color recorded as optional and not implemented unless decided otherwise.
- Small fixes and tests for any concrete issue found.

## Implementation steps

1. Read `Dimens.kt`, `Motion.kt`, the Compose screens, and existing semantics/test tags.
2. Audit interactive elements:
   - icon-only actions have accessible names;
   - streaming announcements are polite and do not announce every token;
   - error/retry actions have clear labels;
   - attachments and message actions have descriptions.
3. Add or update Compose tests for missing content descriptions where practical.
4. Audit minimum touch targets. Use `LocalDimens.current.touchTargetMin` (48 dp) and fix controls that are too small.
5. Run TalkBack on a device/emulator through the required flows and record observations. If TalkBack is unavailable, record the blocker.
6. Verify reduced motion by setting the system animator scale to zero and checking that animations are skipped and content remains visible.
7. Record dynamic color as `optional / not implemented` unless the decision says otherwise.
8. Record results in `M3-verification.md` and the task handoff.

## Acceptance criteria

- [ ] Interactive elements have accessible names or labels.
- [ ] Streaming announcements are sparse and polite.
- [ ] Minimum 48 dp targets are verified.
- [ ] TalkBack pass is recorded for the required flows or blocked explicitly.
- [ ] Reduced motion is verified.
- [ ] Dynamic color is not overclaimed.
- [ ] No translations are added.

## Verification

```bash
make android-lint && make android-test
cd android && ./gradlew :app:connectedDebugAndroidTest
```

Plus the TalkBack and reduced-motion manual checklist.

## Out of scope

- The full M4 cross-platform accessibility audit.
- Localization and translations.
- Dynamic color implementation unless decided in M3-00.2.
- Large visual redesigns.
