## Goal

Prove that rotating or otherwise recreating the activity does not cancel an active stream or lose partial content.

## Preconditions

- M3-05.1 test infrastructure is complete.
- M3-03.4 shell work is complete.
- Do not change the production streaming architecture unless the test exposes a real bug.

## Deliverables

- A device or Robolectric test that starts a controlled stream, recreates the activity, and proves the stream continues.
- Evidence that the same stream, partial text, and message identity survive.
- A manual rotation check recorded if the automated test cannot cover a real configuration change.
- A regression test that no duplicate assistant message is inserted.

## Implementation steps

1. Read `ChatViewModel`, `ChatRunner`, `ChatRoute`, `ChatDependencies`, `ChatMessageList`, and the existing `FakeProviderAdapter`/`TestFixtures`.
2. Choose one harness:
   - instrumentation: add a test activity under `androidTest` that hosts `ChatRoute` with fake dependencies; or
   - Robolectric: drive a test activity with `ActivityController` and the same fake dependencies.
3. The fake adapter must emit a controlled stream with at least two delayed text deltas so the test can observe an active stream before recreation.
4. Start a send, wait until the first partial text is visible, then call `scenario.recreate()` or `controller.configurationChange()`.
5. Assert:
   - the same assistant message id remains;
   - the partial text remains and later deltas still arrive;
   - the fake adapter was not cancelled;
   - no duplicate assistant row is created.
6. Add a manual check: open a local streaming provider, rotate the device during streaming, and record the result.
7. Record the evidence in `M3-verification.md`.

## Acceptance criteria

- [ ] Activity recreation does not cancel the active stream.
- [ ] Partial content survives recreation.
- [ ] Later stream deltas still update the same message.
- [ ] No duplicate assistant message is created.
- [ ] The test runs in CI or the environment blocker is recorded.
- [ ] Manual rotation evidence exists when a device/emulator is available.
