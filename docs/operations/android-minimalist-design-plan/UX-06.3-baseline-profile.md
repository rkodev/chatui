## Implementation steps

1. Replace the literal menu-glyph lookup and nullable optional clicks with
   stable accessible selectors or properly exposed existing test tags.
   A required interaction must fail clearly if the control is absent.
2. Apply/document deterministic onboarding-complete local seed data before
   collection using UX-00.2's procedure. Do not rely on a developer's personal
   install, live provider, paid answer, or unknown prior app state.
3. Exercise useful local startup, history/opening a seeded chat, composer
   interaction, and relocated More/keyboard help. Assert each expected surface
   before continuing and use bounded waits rather than arbitrary long sleeps.
4. Keep setup/seeding outside the collected journey where supported. If the
   existing build cannot be seeded safely, record the exact blocker and seek
   review of a minimal test-only solution; never add a shipping seed backdoor.
5. Preserve API/build requirements of the existing profile module. The app
   remains API 26 compatible even though the producer has its own higher
   minimum; do not raise app minSdk for this test.
6. Generate through the configured app baseline-profile workflow, review the
   actual generated source output, and verify repeatable journey completion.
   Store only intended generated profile sources, not APKs/raw device data.
7. Record device/build/seed identity and profile generation result for
   UX-06.4. Explicitly label this as profile generation, not timing proof.

$adb = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
$serial = 'YOUR_DISPOSABLE_DEVICE_SERIAL'

& $adb -s $serial install -r '.\app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk'

  '-e', 'class', 'dev.chatui.BaselineSeedTest',
  '-e', 'baselineDisposable', 'true', '-e', 'baselineAction')

& $adb -s $serial @seed verify $runner
& $adb -s $serial install -r '.\app\build\outputs\apk\nonMinifiedRelease\app-nonMinifiedRelease.apk'
& $adb -s $serial @seed verify $runner
# Then use the generation command above, without skipGeneration=true.
