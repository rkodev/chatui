## Goal

Render Markdown and code safely on Android and add the M1 message actions.

## Preconditions

- Chat screen and message items exist.
- Add only M1 dependencies.

## Deliverables

- Markdown renderer dependency and integration for headings, lists, tables, blockquotes, task lists, links, inline code, and fenced code.
- Raw HTML is not executed.
- Remote images are blocked by default, regardless of the future `loadRemoteImages` setting.
- Incomplete fenced code during streaming renders as code.
- Code block language label, copy exact text, and a bounded highlighter.
- Message actions: copy message, copy code, regenerate last assistant, edit last user with truncation confirmation, retry failed.
- Tests for XSS inertness, incomplete fences, remote images, copy, and truncation confirmation.

## Implementation steps

1. Add `multiplatform-markdown-renderer-m3` and a suitable highlighting dependency to the catalog and chat feature.
2. Wrap the renderer with a configuration that does not execute raw HTML.
3. Add incomplete-fence handling based on streaming state.
4. Implement image policy to render alt text/link instead of loading remote images.
5. Build a code block component with language label and clipboard copy.
6. Add message action row with accessible labels.
7. Wire actions to the ViewModel.
8. Add tests and run the Android gate.

## Acceptance criteria

- [ ] GFM constructs render correctly.
- [ ] Raw HTML cannot execute.
- [ ] Remote images do not load.
- [ ] Incomplete code fences render as code.
- [ ] Code label and copy work.
- [ ] Copy, regenerate, edit-last-user, and retry work without branching.
- [ ] Android gate passes.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```

## Out of scope

- Math/KaTeX.
- Attachments and image input.
- Branching, message deletion, and export.

Record the renderer configuration, highlighter language set, and clipboard behavior.
