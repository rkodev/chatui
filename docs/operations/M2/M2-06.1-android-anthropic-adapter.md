## Goal

Implement the Android Anthropic adapter with native headers, top-level system prompts, thinking separation, image blocks, and error mapping.

## Preconditions

- M2-00.1 Anthropic vectors exist.
- M2-05.1 generic transport is available.

## Deliverables

- Anthropic discovery and key validation where supported.
- Streaming with `x-api-key` and `anthropic-version`; no web-only browser header required.
- Top-level system prompt.
- Thinking/text separation.
- Base64 image blocks.
- Usage, finish, error, retry, and cancellation mapping.
- Fixture tests and adapter registration.

## Implementation steps

1. Read the Anthropic fixture and expected vector.
2. Implement headers and request body from the shared vectors.
3. Map all Anthropic stream events.
4. Keep thinking separate and do not replay reasoning.
5. Serialize image blocks.
6. Add tests for text, thinking, usage, errors, retry, and cancellation.
7. Register the adapter.
8. Run Android gates.

## Acceptance criteria

- [ ] Anthropic text/thinking fixtures pass.
- [ ] System prompt is top-level.
- [ ] Image blocks serialize correctly.
- [ ] Usage, finish, errors, retry, and cancellation map correctly.
- [ ] No secret leaks.
- [ ] Android gates pass.
