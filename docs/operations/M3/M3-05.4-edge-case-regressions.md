## Goal

Cover the edge cases that are easy to miss even when the happy-path UI tests pass.

## Preconditions

- M3-05.2 is complete.
- Reuse existing M2 tests instead of duplicating them.
- Use synthetic data and fake services only.

## Deliverables

- Tests for share parsing: valid, empty, duplicate, non-text, and warm/cold delivery.
- Tests for deep links: valid, missing conversation, malformed, and onboarding-gated.
- Tests for back ordering: dialog, sheet, drawer, plain navigation.
- Tests for keyboard shortcuts: each action, text-entry safety, overlay priority.
- Tests for persistent drafts: per-conversation isolation, clear on send, bounded eviction.
- Regression coverage for date grouping, search, delete/undo, export/import round trip, invalid import, clear data, and large conversation behavior.
- A coverage map in the handoff notes.

## Implementation steps

1. Inventory existing M2 tests for grouping, search, undo, export/import, invalid import, and clear data. Do not duplicate passing tests; extend them only where M3 changes behavior.
2. Add pure parser tests for share and deep links, including malformed input and repeated delivery.
3. Add navigation tests for share and deep-link cold/warm paths and draft preservation.
4. Add back-order tests for each overlay and the drawer. Prefer state/callback assertions over screenshot timing.
5. Add shortcut tests with Compose key input or a pure shortcut controller.
6. Add draft-store tests for persistence, isolation, clear-on-send, and bounds.
7. Re-run M2 export/import, search, grouping, undo, clear-data, and large-list tests. Add missing assertions only.
8. Record the coverage map and any remaining gaps in the handoff notes.

## Acceptance criteria

### Decisions

- Reused the existing M2 regression suites instead of duplicating them; only missing M3 edge cases were added.
- Added `ExternalIntentEdgeCaseTest` for cold/warm share delivery, malformed deep-link intake, onboarding-gated deep links, and share-during-onboarding with a configured provider.
- Added a dialog back test to `ShellBackNavigationTest` and an all-actions overlay test plus text-entry key assertions to `KeyboardShortcutsTest`.
- Added draft recency-refresh and empty-write-clears cases to `PersistentChatDraftsTest`.
- All tests use fake services, fake conversations, and in-memory drafts. No real keys or live providers are used.
