- Status: Not started

- Depends on: M1-01.2
- Parallel-safe: yes, with M1-02.1
- Owns: `android/core/network/build.gradle.kts`, `android/gradle/libs.versions.toml`, contract copy task, `android/core/network/src/main/kotlin/dev/chatui/core/network/` registry, registry tests
- Read first: [M1 plan](../M1-openrouter-core-implementation-plan.md) sections 2.3, 3.3, and 4.7; spec sections 3.4, 5.3, 7.1, 9.1, 9.2

## Goal

Add Android network dependencies and a provider registry that reads contracts without duplicating provider metadata in Kotlin source.

## Preconditions

- Contracts validate.
- Do not add the adapter or SSE parser in this task.

## Deliverables

- OkHttp, `okhttp-sse`, and MockWebServer test dependencies in the version catalog and `core:network`.
- A Gradle `Copy`/`Sync` task or source-set configuration that makes `contracts/providers.json` and required fixtures available to runtime assets and unit tests.
- `ProviderPreset` data types and `ProviderRegistry` with validation, `getPreset`, and default lookup.
- OpenRouter-only M1 gating helper.
- Tests that load the real contract file and reject malformed presets.

## Implementation steps

1. Update `android/gradle/libs.versions.toml` with pinned OkHttp and MockWebServer entries.
2. Update `android/core/network/build.gradle.kts` with implementation and test dependencies.
3. Add a Gradle task that copies `contracts/providers.json` into generated resources/assets. Do not hand-copy preset values.
4. Add fixtures needed by unit tests to test resources through a similar copy task.
5. Implement serializable preset types and a registry. Use `ChatUiJson` or a local strict-enough JSON parser.
6. Validate required fields, duplicate IDs, and exactly one default/reference/required preset.
7. Add a helper that exposes only OpenRouter for M1 UI.
8. Add tests with the real contract and a malformed fixture.
9. Run Android lint, tests, and assemble.

## Acceptance criteria

- [ ] Network dependencies are in the version catalog, not hard-coded in a module.
- [ ] The registry loads contracts at test/runtime without duplicating provider metadata.
- [ ] Invalid presets fail clearly.
- [ ] OpenRouter is the only usable M1 provider.
- [ ] No adapter or UI is added.
- [ ] Android gate passes.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```

## Out of scope

- HTTP calls and SSE.
- Feature UI.
- Additional providers.

## Handoff notes

Record the contract copy destination, Gradle task name, and registry API.
