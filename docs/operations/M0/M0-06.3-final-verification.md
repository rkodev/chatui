## Final exit gate

Run and record:

```bash
make help
make contracts-install
make contracts-check
make web-lint
make web-typecheck
make web-test
make web-build
make android-lint
make android-test
make android-assemble
git status --short
```

Manual checks:

- Web loads to a themed shell.
- Web repositories survive a refresh.
- Web remember-mode secrets are not plaintext in IndexedDB.
- Web session-mode secrets are lost on reload.
- Android launches to a themed shell.
- Room schema and migration tests pass.
- Android secret storage is ciphertext-only.
- Android backup rules exclude databases and secret stores.
- No provider calls, chat screens, onboarding, sidebar, search, export/import UI, PWA, or service worker exist.
