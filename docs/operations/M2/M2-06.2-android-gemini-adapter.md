## Goal

Implement the Android Gemini adapter with header auth, SSE streaming, system instructions, inline data, usage metadata, and finish mapping.

## Preconditions

- M2-00.1 Gemini vectors exist.
- M2-05.1 generic transport is available.

## Deliverables

- Gemini discovery and chat streaming with `alt=sse` and `x-goog-api-key`.
- `systemInstruction` handling.
- Text and `inlineData` serialization.
- `usageMetadata` and finish mapping.
- Error, retry, and cancellation mapping.
- Fixture tests and adapter registration.

## Implementation steps

1. Read the Gemini fixture and expected vector.
2. Build discovery and chat URLs without the key in the query.
3. Map SSE candidates and parts.
4. Map usage and `STOP`/`MAX_TOKENS`/`SAFETY`/`RECITATION`.
5. Serialize system instruction and inline data.
6. Add tests for text, finish, usage, errors, retry, and cancellation.
7. Register the adapter.
8. Run Android gates.

## Acceptance criteria

- [ ] Gemini text fixtures pass.
- [ ] Finish reasons map correctly.
- [ ] Usage metadata is mapped.
- [ ] API key is header-only.
- [ ] System instructions and inline data serialize correctly.
- [ ] Android gates pass.
