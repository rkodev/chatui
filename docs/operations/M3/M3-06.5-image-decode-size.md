# M3-06.5 - Image decode, Coil sizing, and release size measurement

- Milestone: M3
- Status: Not started
- Order: 31
- Depends on: M3-06.1
- Parallel-safe: yes, with M3-05.*
- Owns: `android/feature/chat/ChatMessageItem.kt`, `ChatComposer.kt`, `ChatMarkdown.kt`, `android/feature/chat/build.gradle.kts`, version catalog if needed, size notes
- Read first: [M3 plan](../M3-android-depth-implementation-plan.md) sections 3.5 and 4.7; spec sections 9.8 and 9.11

## Goal

Avoid full-size bitmap decodes for chat attachments, use Coil for sized/cached local image rendering, and record debug/release artifact sizes.

## Preconditions

- M3-06.1 minified release build works.
- Do not fetch remote images that the user has not allowed.
- Do not change attachment validation, downscale, or EXIF behavior.

## Deliverables

- Chat image rendering uses a size-aware decode or Coil request with caching.
- Composer chips and message images no longer decode full-size bitmaps unnecessarily.
- Debug and release APK/AAB sizes are measured and recorded.
- The 20 MB debug / 15 MB release budgets are met or the miss is documented with a cause.

## Implementation steps

1. Read `ChatMessageItem.kt`, `ChatComposer.kt`, `ChatMarkdown.kt`, `AndroidImageProcessor`, and the feature build file.
2. Add Coil to the chat module from the existing version catalog (`coil-compose`, and `coil-network-okhttp` only if remote image loading is retained).
3. Replace `BitmapFactory.decodeFile(file.path)` in message and composer rendering with Coil `AsyncImage`/`ImageRequest` using:
   - the target size or a bounded max height (for example 320 dp);
   - local `File` data;
   - memory/disk cache as appropriate;
   - the existing content description.
4. Keep Markdown remote-image behavior unchanged unless the user setting allows it. Do not add hidden network fetches.
5. Remove now-unused full-size bitmap decode code only if no other caller needs it.
6. Build and measure:
   ```bash
   cd android
   ./gradlew :app:assembleDebug :app:assembleRelease :app:bundleRelease
   ls -l app/build/outputs/apk/debug/app-debug.apk
   ls -l app/build/outputs/apk/release/app-release.apk
   ls -l app/build/outputs/bundle/release/app-release.aab
   ```
7. Record the sizes and any obvious largest contributors in the handoff.
8. Run the chat image tests and a device/emulator check with a large image.

## Acceptance criteria

- [ ] Message and composer images are decoded at a bounded size.
- [ ] Coil caching is used or an equivalent bounded decode is proven.
- [ ] No hidden remote fetch is introduced.
- [ ] Content descriptions remain correct.
- [ ] Debug and release APK/AAB sizes are recorded.
- [ ] Size budgets are met or the miss is documented.
- [ ] Image tests pass.

## Verification

```bash
make android-lint && make android-test && make android-assemble
cd android && ./gradlew :app:assembleRelease :app:bundleRelease
```

## Out of scope

- Changing image validation or downscale limits.
- Remote-image settings behavior.
- Baseline profiles (M3-06.3) and performance evidence (M3-07.1).
