## Handoff notes

- Math renderer and bundle impact: `remark-math` parses inline/block math and `MathRenderer` lazy-loads `katex`. KaTeX JS is emitted as a separate 259 kB chunk (77.7 kB gzip) and is only requested when math is present. KaTeX CSS and font assets are emitted by the build; CSS is currently in the main stylesheet. Rendering uses `trust: false`, `throwOnError: true`, and expansion/size limits; parse or load failures show the raw TeX source.
- Remote-image policy: `MarkdownRenderer` and `MessageItem` accept `loadRemoteImages`, defaulting to `false`. Without it, safe http/https images show a blocked note plus a per-message "Load image" action and an "Open image" link. Data, javascript, mailto, anchor, and relative image sources are never loaded. Loaded images use `loading="lazy"` and `referrerPolicy="no-referrer"`. The settings UI and session plumbing that supplies `loadRemoteImages` are deferred to M2-03.4, which consumes this contract.
- Deferred content cases: reasoning remains plain text inside the collapsed `<details>` block; math inside fenced code stays code; no image proxying or CSP changes are added here.
