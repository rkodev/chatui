## Goal

Create a buildable, lintable, testable React 19 web scaffold with the M0 dependency set and the folder layout. Do not add provider adapters or feature screens.

## Preconditions

- Contracts validate and `make contracts-check` passes.
- No root Node workspace or root `package.json` exists. Keep web dependencies isolated under `web/`.

## Deliverables

- `web/package.json` with:
  - `"packageManager": "pnpm@11.7.0"` or the pinned pnpm version used by the project
  - scripts: `dev`, `build`, `preview`, `lint`, `typecheck`, `test`, `test:watch`, `format`, `format:check`
  - runtime dependencies: React 19, React DOM 19, `@tanstack/react-router`, `zustand`, `idb`, `zod`, `uuid`
  - development dependencies: TypeScript, Vite, `@vitejs/plugin-react`, Vitest, jsdom, Testing Library packages, MSW, `fake-indexeddb`, ESLint, `typescript-eslint`, Prettier
  - no Tailwind, PWA plugin, Markdown renderer, Shiki, virtualization, or Playwright in M0
- `web/pnpm-lock.yaml`, generated and committed.
- TypeScript configuration with strict mode and a DOM library setup.
- Vite configuration with the React plugin, test configuration, and history-routing-friendly dev server.
- ESLint and Prettier configuration compatible with TypeScript and React 19.
- `index.html`, `main.tsx`, and a minimal `App.tsx` that render a neutral placeholder shell. The real router and design system arrive in M0-03.
- Test setup file that registers `@testing-library/jest-dom`, `fake-indexeddb/auto`, and any needed browser polyfills.
- Folder placeholders matching spec 8.2:
  `src/app`, `src/domain`, `src/providers`, `src/storage`, `src/features/{chat,conversations,providers,settings,onboarding,attachments}`, `src/platform`, `src/ui`, `src/styles`, `src/test`.
  Use `.gitkeep` or small placeholder files. Do not implement provider code.
- Remove `web/.gitkeep`.

## Implementation steps

1. Create `web/package.json` and install with pnpm.
2. Add TypeScript, Vite, ESLint, Prettier, and Vitest configuration.
3. Add a minimal render entry point and one smoke test.
4. Create all placeholder folders from spec 8.2.
5. Run all web commands and fix configuration errors.
6. Commit the lockfile and confirm no root dependency files were created.

## Acceptance criteria

- [ ] `pnpm install --frozen-lockfile` succeeds after the lockfile is committed.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build` pass.
- [ ] The app renders a minimal shell in the browser.
- [ ] The folder layout matches spec 8.2, with provider and feature folders left as placeholders.
- [ ] No root `package.json`, root lockfile, or pnpm workspace file exists.
- [ ] No provider adapter or feature UI exists.

## Verification

```bash
cd web && pnpm install --frozen-lockfile
cd web && pnpm lint
cd web && pnpm typecheck
cd web && pnpm test
cd web && pnpm build
```

## Out of scope

- Runtime config, domain types, storage, secrets, router, tokens, and primitives.
- PWA, service worker, deployment files, and Playwright.
