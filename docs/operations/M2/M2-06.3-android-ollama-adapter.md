## Handoff notes

- Adapter registration: `OllamaAdapter` implements `CatalogAdapter` and is
  registered by `presetId` in `ProviderAdapterRegistry` because Ollama's
  contract kind is `openai-compatible`. `RoutingProviderAdapter` and
  `RoutingProviderGateway` now dispatch through the context-aware registry
  overloads, so the Ollama preset reaches the native adapter while other
  OpenAI-compatible presets keep the shared transport. `ollama` is enabled in
  `M2_ENABLED_PRESET_IDS`.
- Native/fallback selection: native NDJSON is the default for the `ollama`
  preset. A request may set `params.extra.ollama.transport` (or `mode`) to
  `native` or `openai-compatible`; any other preset id selects the
  OpenAI-compatible fallback. The control field is stripped before the fallback
  body is serialized. Native chat uses `POST {nativeBase}/api/chat`; discovery
  uses `GET {nativeBase}/api/tags`, where `nativeBase` strips a trailing `/v1`
  from the provider base URL.
- Request body: the system prompt is the first message. Text and text-file parts
  become `content`; images become the `images` base64 array. Generation controls
  live under `options` (`num_predict`, `temperature`, `top_p`, `stop`). Advanced
  JSON under `params.extra.ollama` cannot override `model`, `messages`,
  `stream`, or `stream_options`, and `transport`/`mode` are never forwarded.
- Stream mapping: `message.content` maps to `text-delta`, `message.thinking` to
  `reasoning-delta`, `prompt_eval_count`/`eval_count` to `Usage`, and `done`
  with `done_reason` to `finish`. Missing `done_reason` maps to `stop`; unknown
  values map to `unknown`. The NDJSON reader normalizes CRLF/LF/lone CR, bounds
  an incomplete line at 1 MiB, and flushes the final partial line.
- Error mapping: HTTP 401 to `auth`, 402 to `quota`, 403 to `permission` unless
  moderation-related, 404 to `model_not_found`, 413 to `context_length`, 429 to
  `rate_limit` with `Retry-After`, 400 context messages to `context_length`, and
  5xx to retryable `provider`. In-stream `error` envelopes map by `status` with
  `retryable = false`. Retries happen only before any text or reasoning delta.
  Cancellation cancels the OkHttp call.
- Cleartext note: Android blocks cleartext HTTP by default, so a local
  `http://localhost:11434` endpoint needs a network security config that permits
  cleartext only for `localhost` and private-range hosts, plus an explicit user
  warning. `OLLAMA_CLEARTEXT_GUIDANCE` records this copy. The adapter never
  weakens TLS validation globally. The app manifest/network-security wiring is
  left to the settings/security task because this task owns the network layer.
- Deferred cases: the app manifest does not yet include a network security
  config, so a real device cannot reach a cleartext local Ollama server until
  that wiring lands. `ModelService.refreshModels` still passes no API key to
  discovery; Ollama needs none, so native `/api/tags` works.
