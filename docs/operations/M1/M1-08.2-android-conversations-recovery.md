## Handoff notes

### Navigation arguments

`ChatDestination.ROUTE` is `chat/{conversationId}` with
`ChatDestination.ARG_CONVERSATION_ID = "conversationId"`. The bare
`ShellDestination.Chat` route (`chat`) remains for the bottom navigation and
onboarding hand-off. `ChatDestination.createRoute(id)` URI-encodes the id.
`ShellDestination.matches` treats any `chat/...` route as the Chat destination
so the bottom bar and top bar stay selected. The chat destination currently
renders `ChatPlaceholder` with a test tag carrying the id; M1-09 replaces the
placeholder with the real chat screen.

### Grouping helper

`groupConversationsByDate(conversations, now, zoneId)` is a pure helper in
`ConversationGrouping.kt`. It compares local calendar dates in the supplied
zone, treats future timestamps as Today, omits empty buckets, and sorts each
bucket newest-first by `lastMessageAt`. Buckets are Today, Yesterday, Previous
7 days, Previous 30 days, and Older. `formatConversationTimestamp` renders the
row timestamp (time today, month/day this year, year/month/day otherwise).

### New chat and last-active restore

`DefaultConversationService.createConversation` prefers the configured default
provider/model, falls back to the first enabled provider and its first
non-hidden text-output model, and returns a typed `NotConfigured` message when
nothing is available. It records the new conversation as last active.
`getLastActiveConversation` clears a stale pointer. `shellStartDestination`
returns onboarding until setup completes, then the last-active chat route when
one is recorded, otherwise the conversation list.

### Undo decision

Undo was omitted. Delete always opens a confirmation dialog, which is the
safety mechanism required by the task. A buffered 5-second undo would need a
shell-level Snackbar host and delayed-delete state; that work is deferred so it
does not overlap M1-08.3's persistence/recovery tests. The delete path itself
hard-deletes the conversation and its messages through the existing repository
transaction.

### Scope

No search, pin, archive, export/import, tablet layout, chat screen, composer, or
process-death recovery was added. The conversation drawer composable is present
for M1-09 to mount around the chat screen.
