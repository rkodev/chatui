## Goal

Add the M2 web end-to-end suite with deterministic mocked providers and the required lifecycle flows.

## Preconditions

- Web M2 features and paths are implemented.
- A deterministic mock provider/SSE mechanism is available.

## Deliverables

- Playwright configuration and scripts.
- Deterministic mock provider and SSE fixtures.
- E2E flows: first-run onboarding with OpenRouter, send/stream with mocked provider, switch model/provider mid-conversation, reload persistence, export/import round trip, delete/undo, clear data, offline read, error/retry/cancel.
- Accessibility smoke checks where practical.
- CI-compatible artifacts and bounded runtime.

## Implementation steps

1. Add Playwright dependencies and config.
2. Build a deterministic provider mock for onboarding, discovery, streaming, errors, and retry.
3. Add the required E2E tests one flow at a time.
4. Keep tests independent and reset local storage between runs.
5. Capture failure artifacts without secrets.
6. Add a package script and update CI when appropriate.
7. Run the full suite and fix flakes.

## Acceptance criteria

- [ ] Playwright configuration exists and runs.
- [ ] All required M2 flows are covered.
- [ ] Mock providers are deterministic and secret-free.
- [ ] Tests are isolated and repeatable.
- [ ] Failure artifacts are bounded and redacted.
- [ ] `cd web && pnpm exec playwright test` passes.

cd web && pnpm exec playwright test

## Out of scope

- Android E2E or Compose UI tests.
- Live provider calls.
- M4 deployment/Lighthouse work.
