## Goal

Add the Slint History view and a controller that binds `ConversationHistory` and
`ConversationSearchService` to a real, interactive sidebar: groups, new chat,
archive, load-more, rename, delete with undo, drafts, and search.

## Preconditions

- `M3.6-02.1` provides the shared runtime and repositories.
- `M3.6-03.1` provides the shell host container and factory property.
- Do not change the history view model contract unless a test requires it.
- Do not load the entire conversation table in one query.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- `conversations/view.rs` with:
  - a `HistoryWindow` Slint component: grouped list, active row, draft badge,
    archived toggle, load-more, new chat, rename field, delete with undo,
    search field and bounded results;
  - `sync_window` that maps `HistoryState` and search state to Slint models;
  - `HistoryController` that owns the async history and search services and a
    runtime handle, exposes the window, and wires callbacks.
- Async behavior:
  - load, refresh, load-more, search, new chat, rename, archive, delete/undo on
    the runtime;
  - results marshalled to the Slint event loop;
  - no blocking storage calls on the Slint thread.
- Exports from `conversations/mod.rs` and `lib.rs`.
- Component and controller tests with a temporary database.

## Implementation steps

1. Define the Slint component and its properties/callbacks.
2. Write `sync_window` for groups, rows, drafts, pending delete, status, and
   search.
3. Build `HistoryController` over `ConversationHistory`,
   `ConversationSearchService`, and a runtime handle.
4. Wire new chat, selection, rename, archive toggle, load-more, search, delete,
   and undo.
5. Keep delete undo timing consistent with `DEFAULT_UNDO_WINDOW`.
6. Marshal async results through `slint::Weak::upgrade_in_event_loop` or a
   short poll timer.
7. Ensure empty, loading, and error states render.
8. Add tests for grouping, search, rename, archive, delete/undo, drafts, and
   navigation.
9. Export the controller and window from the crate root.

## Acceptance criteria

- [ ] `HistoryController` creates the view and loads the first page.
- [ ] Groups and row order match `group_conversations`.
- [ ] New chat creates and selects a conversation.
- [ ] Rename, archive, and delete/undo persist.
- [ ] Search returns bounded results with snippets and handles empty/error.
- [ ] Draft badges appear for persisted drafts.
- [ ] Load-more grows the bounded window.
- [ ] No blocking storage call runs on the Slint thread.
- [ ] Tests pass with a temporary database.
