## Goal

Deliver a safe, accessible composer with per-conversation drafts, send-key behavior, stop control, and correct disabled states.

## Preconditions

- ChatRunner exposes send, stop, and streaming state.
- Typed settings expose `sendKey`.

## Deliverables

- Auto-grow textarea from 1 to 8 lines, then internal scroll.
- Enter vs Mod+Enter behavior from settings, Shift+Enter newline.
- Per-conversation drafts persisted in a Zustand store and restored on conversation switch.
- Send button and stop button with clear labels.
- Disabled when empty, streaming, offline, no provider, or model unavailable.
- Preserve typed text on send failure.
- Focus management when switching conversations.
- Tests for keyboard behavior, drafts, disabled states, and text preservation.

## Implementation steps

1. Read the existing Button primitives and drafts store.
2. Build the textarea with a measured auto-grow implementation.
3. Implement the keydown handler using the current `sendKey` setting.
4. Store drafts by conversation ID and restore on route change.
5. Wire send to `ChatRunner` and stop to the active stream cancel.
6. Add offline detection through `navigator.onLine` and an event listener.
7. On send failure, restore the draft and leave focus in the composer.
8. Add tests with user-event.

## Handoff notes

- Draft key format: `useDraftStore.drafts[conversationId]` is the complete composer text. Typing updates the store on every change, a successful send calls `clearDraft(conversationId)`, and a failed or thrown send restores the original text. Switching conversations restores whatever draft exists for that ID.
- Focus behavior: the textarea focuses when `conversationId` changes and the composer is enabled. A failed send restores the draft and returns focus to the textarea. The composer does not steal focus when it is disabled.
- Send-key semantics: in `enter` mode, plain Enter and Mod+Enter send; in `mod-enter` mode only Mod+Enter sends, while plain Enter inserts a newline. Shift+Enter always inserts a newline, and IME composition Enter is ignored.
- Disabled states: send is disabled for an empty draft, an in-flight send, an active stream, offline browser state, no provider, unavailable model, or a session that is not ready. Offline state uses `navigator.onLine` plus `online`/`offline` listeners.
- Auto-grow: the textarea measures `scrollHeight`, clamps between one and eight computed line heights, and switches to internal scrolling above the cap.
