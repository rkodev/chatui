- Read first: [M3.5 plan](../M3.5-rust-desktop-implementation-plan.md) sections 3.5 and 4.8; spec sections 7.4, 7.8, 11.5

## Goal

Implement OpenRouter key introspection and public catalog mapping with a 24-hour cache and last-known-good fallback.

## Preconditions

- The shared HTTP client and contract types exist.
- Do not implement chat streaming or additional providers.
- Do not put keys in URLs.
- Do not copy the OpenRouter catalog or presets into source.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- `validate_key` using `GET /key` with `Authorization: Bearer`.
- `ProviderKeyInfo` mapping for label, usage, limit, free tier, and rate limit.
- Public `GET /models` catalog loading before key validation.
- Mapping to the shared `Model` shape, including:
  - `remoteId`, `canonicalSlug`, `label`;
  - context and max output;
  - input/output modalities;
  - capabilities from supported parameters and modalities;
  - per-million pricing from per-token strings;
  - free models and `:free` suffix;
  - metadata for unknown or provider-specific fields.
- A cache trait with in-memory and file-backed implementations.
- 24-hour TTL and last-known-good snapshot on refresh failure.
- Tests using `contracts/fixtures/models/openrouter-key.json`, `openrouter-models.json`, and expected vectors.

## Implementation steps

1. Read spec section 7.4 and `web/src/providers/openrouterCatalog.ts`, `openaiCatalog.ts`.
2. Implement the `/key` request and response mapping. Use decimal handling for USD values; do not use binary floating point for final display rounding decisions.
3. Implement the public `/models` request. It must work before a key is present.
4. Map the catalog fields exactly as section 7.4 requires. Keep raw pricing and unknown small fields in `metadata`.
5. Parse per-token prices as decimals and multiply by 1,000,000 for per-million display values.
6. Mark zero-priced models as free and preserve the `:free` suffix in `remoteId`.
7. Ignore unknown catalog fields rather than failing the whole catalog. Do not put secrets or conversation content in `metadata`.
8. Implement the cache trait:
   - `get(provider_id)`;
   - `put(provider_id, snapshot, fetched_at)`;
   - freshness check using the preset TTL (86,400 seconds for OpenRouter).
9. Implement a file-backed cache under the app-data directory. Use JSON and a versioned shape. Keep no secrets.
10. On refresh failure, return the last-known-good snapshot with a stale flag and refresh error. If no snapshot exists, return the error.
11. Add tests for paid, free, vision, reasoning, tool, and long-context models; unusual pricing strings; unknown fields; stale fallback; and cache TTL.
12. Record the cache path and snapshot format.

## Handoff notes

- APIs:
  - `openrouter::key::validate_key(&HttpClient, base_url, api_key)` sends `GET /key` with `Authorization: Bearer` and returns `ProviderKeyInfo`.
  - `openrouter::key::map_key(&Value)` maps the `/key` envelope without network access.
  - `openrouter::catalog::list_models(&HttpClient, base_url)` sends public `GET /models` with no authorization header.
  - `openrouter::catalog::map_models(&Value)` / `map_model(&Value)` normalize catalog entries into `CatalogModel`.
  - `CatalogModel::to_model(id, provider_id, created_at, updated_at)` converts to the shared `chatui_domain::Model` shape.
  - `openrouter::cache::load_catalog(...)` and `refresh_catalog(...)` implement the TTL and last-known-good behavior.
- Cache path and format:
  - Default path: `<platform app-data>/catalogs/<provider-id>.json` (`FileCatalogCache::default_path`).
  - Versioned JSON: `{ "version": 1, "providerId": "...", "fetchedAt": "<RFC3339>", "models": [...] }`.
  - Writes use a temporary file plus rename. The cache stores only public catalog data; no keys, headers, prompts, or conversation content.
- Mapping decisions:
  - Per-token prices are multiplied by 1,000,000 with exact decimal-string arithmetic (`multiply_decimal_by_million`); binary floating point is used only after the exact conversion for the shared `ModelPricing` fields.
  - Raw pricing, `architecture.modality`, tokenizer, `default_parameters`, `top_provider` flags, `per_request_limits`, description, and small non-secret unknown fields are kept in `metadata`.
  - Unknown fields whose names look secret-like (`key`, `token`, `secret`, `auth`, `password`, `credential`) are never copied.
  - Free models are zero effective price or a `:free` suffix; the suffix is preserved in `remoteId`.
  - `canonical_slug` deduplication is display-only (`dedupe_by_canonical_slug`); distinct remote IDs remain selectable.
  - Embedding-like IDs are marked `hidden`.
- Tests: `rust/crates/chatui-providers/tests/openrouter_catalog.rs` covers paid, free, vision, reasoning, tool, long-context, unusual pricing, unknown fields, malformed entries, key mapping, public catalog loading, HTTP errors, cache TTL, file cache round-trip, stale fallback, and no-secret cache contents.
