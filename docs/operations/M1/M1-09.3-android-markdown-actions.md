- Markdown renderer dependency and integration for headings, lists, tables, blockquotes, task lists, links, inline code, and fenced code.
- Raw HTML is not executed.
- Remote images are blocked by default, regardless of the future `loadRemoteImages` setting.

## Handoff notes

### Renderer configuration

- Dependencies: `com.mikepenz:multiplatform-markdown-renderer-m3:0.46.0` and
  `dev.snipme:highlights:1.2.0`.
- GFM is enabled through the renderer's default `GFMFlavourDescriptor`, which
  covers headings, lists, tables, blockquotes, task lists, strikethrough,
  autolinks, inline code, and fenced code.
- Raw HTML is never parsed as markup. Inline HTML tokens are appended as
  inert text by the annotator, and top-level HTML blocks use a custom
  component that renders the original source text. Raw HTML inside code is
  unchanged. There is no WebView.
- Inline links and GFM autolinks outside the `http`, `https`, `mailto`, and
  `#anchor` allowlist are rendered as plain text. Remote images are handled by
  `NoOpImageTransformerImpl`, so no image loader is invoked, and a custom
  inline/block component renders the alt text plus "Remote images are
  blocked." The future `loadRemoteImages` setting is intentionally ignored in
  M1.
- An unterminated fence is closed only for the rendered copy by
  `closeIncompleteFence`; persisted message text is never mutated. Fenced code
  is extracted from the AST so the language label and copied text match the
  source.

### Highlighter language set

- Supported: `C`, `CPP`, `CSHARP`, `JAVA`, `KOTLIN`, `RUST`, `JAVASCRIPT`,
  `TYPESCRIPT`, `PYTHON`, `RUBY`, `PHP`, `GO`, `SWIFT`, `SHELL`, `DART`,
  `PERL`, and `COFFEESCRIPT`.
- Aliases include `kt`, `kts`, `js`, `jsx`, `ts`, `tsx`, `py`, `rb`, `c++`,
  `cc`, `cs`, `c#`, `sh`, `bash`, `zsh`, `shellscript`, and `golang`. Unknown
  fence labels still render as plain monospace text with the original label.

### Clipboard behavior

- Code blocks copy the exact source text without the fence; the header button
  shows `Copied` for 1.5 seconds.
- Message copy joins every text part with a blank line (`\n\n`), matching the
  web client.
- Both paths use `LocalClipboardManager.setText`, which maps to the Android
  clipboard. Tests inject copy callbacks to assert the exact text.

### Actions

- Copy is always available on persisted messages.
- Regenerate is offered only on the last assistant message; edit is offered
  only on the last user message. Both are disabled while sending or streaming
  and are hidden on the active streaming row.
- Edit opens a confirmation dialog that warns every later message will be
  deleted. Confirming calls `ChatViewModel.onEditAndResend`, which delegates to
  `ChatRunner.editAndResend` to truncate later rows and resend in place. No
  branch or alternate conversation is created.
- Retry remains the inline action on failed/cancelled messages.
