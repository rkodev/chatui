## Goal

Add Android conversation search using existing FTS data with debounce, result grouping, and correct states.

## Preconditions

- M2-06.5 conversation/settings surfaces exist.
- FTS4 DAO query exists.

## Deliverables

- Repository/service search API joining FTS results back to conversations.
- Debounced search UI with title/message matches.
- Loading, empty, and error states.
- Stale-query protection.
- Tests for matching, cancellation, and states.

## Implementation steps

1. Read `MessageDao.search`, `MessageRepository.search`, and `ConversationListScreen`.
2. Add a conversation-search service with debounce and cancellation.
3. Add result models and grouping.
4. Add the sidebar search UI and states.
5. Add tests.
6. Run Android gates.

## Acceptance criteria

- [ ] Search finds title and message matches.
- [ ] Results are grouped and show useful context.
- [ ] Debounce/cancellation prevent stale results.
- [ ] Loading/empty/error states exist.
- [ ] UI does not scan all messages.
- [ ] Android gates pass.
