## Goal

Implement a provider-agnostic Android SSE transport with OkHttp that matches the web transport behavior and supports cancellation.

## Preconditions

- OkHttp and `okhttp-sse` are available.
- Do not map OpenRouter JSON in this task.

## Deliverables

- SSE line/event parser that handles CRLF/LF, multi-line `data:`, comments, unknown fields, and final flush.
- Bounded buffering with a typed transport error.
- Cancellation from coroutine cancellation to the OkHttp call.
- An API that emits raw data strings or events to the adapter.
- MockWebServer tests for chunked responses, keep-alives, split chunks, final buffer, malformed data, and cancellation.

## Implementation steps

1. Read spec 9.6 and the web SSE task expectations.
2. Choose `okhttp-sse` if it exposes enough control; otherwise implement a bounded line reader over the response body.
3. Normalize line endings and collect `data:` lines per event.
4. Ignore comment and unknown fields.
5. Enforce a maximum event/buffer size.
6. Process the final partial event when the body ends.
7. Ensure cancellation closes the response and cancels the call.
8. Add MockWebServer tests with `MockResponse.setBody`/chunked bodies.
9. Run the Android gate.

## Acceptance criteria

- [ ] Keep-alives produce no data events.
- [ ] Multi-line data is concatenated.
- [ ] Split chunks do not lose or duplicate data.
- [ ] Final buffer is handled.
- [ ] Buffer size is bounded.
- [ ] Cancellation does not hang and cancels the HTTP call.
- [ ] No provider JSON is parsed here.
- [ ] Android gate passes.
