## Goal

Add debounced conversation search across titles and message text with correct loading, empty, and error states.

## Preconditions

- M2-03.4 settings routes are reachable.
- M1 conversation repository and message store are stable.

## Deliverables

- Repository-level search API for conversation titles and message text.
- Index or bounded cursor-scan strategy that does not scan the entire store on every keystroke.
- Debounced search field in the conversation sidebar.
- Grouped results with title/message match context.
- Empty, loading, and error states.
- Keyboard and screen-reader accessible behavior.
- Tests for matching, debounce, cancellation, and states.

## Implementation steps

1. Read `ConversationRepository`, `MessageRepository`, and `ConversationSidebar`.
2. Choose and document the search strategy.
3. Add the search API and tests.
4. Add the debounced sidebar search and result grouping.
5. Add loading/empty/error states.
6. Ensure stale results cannot overwrite newer queries.
7. Run web gates.

## Acceptance criteria

- [ ] Search matches conversation titles and message text.
- [ ] Results are grouped and display useful context.
- [ ] Empty/loading/error states are implemented.
- [ ] Debounce and cancellation prevent stale results.
- [ ] The UI does not scan all messages on every keystroke.
- [ ] Web gates pass.
