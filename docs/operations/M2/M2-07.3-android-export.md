## Goal

Implement Android per-conversation JSON/Markdown export and a full `chatui.export` archive with secrets excluded by default.

## Preconditions

- M2-00.2 export fixture exists.
- Settings data entry exists from M2-06.5.

## Deliverables

- Per-conversation JSON and Markdown export.
- Full archive matching the shared schema.
- Secrets excluded by default and plaintext warning.
- Optional attachment bytes.
- Preservation of IDs, order, snapshots, and attachment references.
- SAF/document export and tests.

## Implementation steps

1. Read the export schema and fixture.
2. Add a repository-level export reader.
3. Add JSON/Markdown formatters.
4. Add archive assembly and optional attachment payloads.
5. Add SAF export and warning.
6. Add schema validation and preservation tests.
7. Run Android gates.

## Acceptance criteria

- [ ] JSON and Markdown exports work.

- [ ] Attachment bytes are optional.
- [ ] Android gates pass.
