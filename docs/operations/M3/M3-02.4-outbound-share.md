# M3-02.4 - Outbound conversation share

- Milestone: M3
- Status: Not started
- Order: 17
- Depends on: M3-00.2, M3-02.1
- Parallel-safe: yes, with M3-02.2 and M3-02.3
- Owns: chat/conversation share UI and formatter, share tests
- Read first: [M3 plan](../M3-android-depth-implementation-plan.md) sections 3.2 and 4.4; spec sections 9.10 and 11.7; M3-00.2 outbound-share decision

## Goal

Share a conversation as plain text or Markdown through `ACTION_SEND` without including secrets or local attachment bytes.

## Preconditions

- M3-00.2 confirms whether this task is active. If outbound sharing is deferred, mark this task `Cancelled` with the decision reference and stop.
- M3-02.1 must be complete for the shared intent-channel patterns.
- Do not include API keys, provider headers, attachment bytes, or internal file paths.

## Deliverables

- A pure conversation-to-text/Markdown formatter.
- A user action to share a conversation or completed response.
- `ACTION_SEND` text/plain chooser integration.
- Tests for formatting and intent construction.

## Implementation steps

1. Read `ChatMessageActions.kt`, `ChatScreen.kt`, `ConversationSettingsSheet.kt`, `Message`, `ContentPart`, and the existing Markdown renderer.
2. Add a pure formatter that accepts a conversation title and message list and returns text:
   - include role labels and text parts;
   - include reasoning only if M3-00.2 says so; default to excluding it;
   - exclude image/file bytes and storage keys;
   - keep attachment names only if they are not sensitive;
   - never include provider keys or request metadata.
3. Add a Share action in a sensible surface: conversation settings, chat header overflow, or the message action row. Use one entry point; do not duplicate it in many places.
4. Build `Intent.createChooser(Intent(ACTION_SEND).apply { type = "text/plain"; putExtra(EXTRA_TEXT, text) }, title)`.
5. Add tests for:
   - formatter includes messages in order;
   - no secret or attachment bytes appear;
   - empty conversation produces a safe result;
   - the action builds a `text/plain` send intent.
6. Record a manual share check on a device/emulator.

## Acceptance criteria

- [ ] A conversation can be shared as text/Markdown.
- [ ] The chooser receives a `text/plain` intent.
- [ ] No key, secret header, attachment bytes, or file path is included.
- [ ] The action is reachable and accessible.
- [ ] Tests pass.
- [ ] If deferred, the task is cancelled with the decision reference and no code is added.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```

Plus a manual share check.

## Out of scope

- Sharing images or files.
- Inbound share target (M3-02.1).
- Export/import archives.
