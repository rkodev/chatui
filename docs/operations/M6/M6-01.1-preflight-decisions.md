## Goal

Close the M6 entry gate by recording the product, hosting-boundary, staging,
feature-flag, and privacy-review decisions that every later task depends on. No
templates or documentation should be finalized before these decisions exist.

## Preconditions

- M4 and M5 are complete and their verification records exist.
- The user has authorized M6 work.
- If a decision owner is unavailable, record the item as a blocker instead of
  inventing an answer.

## Deliverables

- `docs/operations/M6/M6-decisions.md` with dated entries. Cover at least:
  - `DEC-M6-01`: M6 authorization and confirmation that this is a
    hosting/documentation milestone, not a backend build.
  - `DEC-M6-02`: repository versus external-operator boundary. The repository
    owns static artifacts, schemas, templates, docs, and evidence; the external
    operator owns the control plane, DNS, TLS, status, and support tooling.
  - `DEC-M6-03`: product name, domain, branding owner, and support model.
  - `DEC-M6-04`: tenant model. Use a private operator manifest plus the public
    app `config.json`; no secrets in either served artifact.
  - `DEC-M6-05`: tenant manifest location, recommended
    `contracts/schema/hosting-tenant.schema.json` with fixtures under
    `contracts/fixtures/hosting/`.
  - `DEC-M6-06`: feature-flag decision. Expose none in M6, or add a typed,
    allowlisted public flag shape.
  - `DEC-M6-07`: subdomain and region policy, including what "region" means and
    the data-residency statement.
  - `DEC-M6-08`: BYO storage only. No roksky-managed storage offering in M6.
  - `DEC-M6-09`: support-access model. Least privilege, no impersonation, no
    access to keys, plaintext chats, storage credentials, or backup
    passphrases.
  - `DEC-M6-10`: named external staging operator, staging tenant, custom-domain
    test path, and TLS access.
  - `DEC-M6-11`: named privacy/legal reviewer and approval process.
  - `DEC-M6-12`: logging fields and retention periods.
  - `DEC-M6-13`: PWA install name/icon branding decision and limitation.
  - `DEC-M6-14`: custom-domain and TLS ownership, renewal, and failure handling.
  - `DEC-M6-15`: release pinning and rollback ownership.
- Update the entry-gate checklist in `docs/operations/M6/README.md` with checked
  items or recorded blockers.
