## Goal

Create shared normalized expectations for every non-OpenRouter stream and error fixture so web and Android adapters have the same target.

## Preconditions

- M1 is complete and its expected OpenRouter vectors still pass.
- Do not modify client source in this task.

## Deliverables

- Expected normalized event sequences for `openai-text.sse`.
- Expected normalized event sequences for `openai-reasoning.sse`, including reasoning and text separation.
- Expected normalized event sequences for `anthropic-text.sse`, including thinking/text separation where the fixture supports it.
- Expected normalized event sequences for `gemini-text.sse`, including `STOP`, `MAX_TOKENS`, `SAFETY`, and `RECITATION` mapping cases.
- Expected normalized event sequences for `ollama-ndjson.txt`, including final usage.
- Expected normalized keep-alive, in-stream error, and 429 behavior.
- Normalized `ChatError` expectations for auth, permission, rate limit, quota, model not found, context length, content filter, network, timeout, and provider failures.
- Validator support and a deliberate-broken-vector test.

## Implementation steps

1. Read the existing OpenRouter expected vectors and keep their shape as the canonical format.
2. Add one expected JSON file per non-OpenRouter stream fixture under `contracts/fixtures/expected/`.
3. Add provider-specific error fixtures under `contracts/fixtures/errors/` for HTTP and in-stream failures.
4. Define expected normalized errors with stable codes, retryability, status, and request ID behavior.
5. Extend `scripts/validate-contracts.mjs` to validate the new expected files and fail on drift.
6. Add a broken-vector validation case so the validator reports a precise file and field.
7. Run the contract gate.

## Acceptance criteria

- [ ] All non-OpenRouter stream fixtures have expected normalized outputs.
- [ ] Expected outputs distinguish reasoning from answer text where applicable.
- [ ] Anthropic thinking/text, Gemini finish mapping, and Ollama usage are covered.
- [ ] Error expectations cover HTTP and in-stream cases without secrets.
- [ ] `make contracts-check` passes with the new vectors.
- [ ] A deliberately broken vector fails with an actionable message.
- [ ] OpenRouter expected vectors are unchanged.
