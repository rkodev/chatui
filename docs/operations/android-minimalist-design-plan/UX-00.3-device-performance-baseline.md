## Goal

Establish controlled physical-device measurements and agreed comparison
conditions before visual changes, so "better on basic phones" is measurable.

## Read first

Read the [execution contract](README.md), source-plan sections 7 and 10,
UX-00.2's fixture/build recipe, and
`android\baselineprofile\src\main\java\dev\chatui\baselineprofile\StartupBaselineProfile.kt`.
Profile generation is not a startup/frame timing benchmark.

## Owns

Measurement protocol/results, artifact references, reference-device matrix,
and agreed-budget record in this task's Handoff notes. No production code, scheduling,
SDK, dependency, or provider changes.

## Deliverables

Named entry-level and mid-tier reference hardware, comparable baseline
startup/frame/memory results, and a repeatable protocol for UX-06.4.

## Implementation steps

1. Record actual device model, RAM, API, refresh rate, navigation mode, font
   scale/density, app/build identity, power/thermal conditions, and data reset
   procedure. Do not invent a device or reuse old milestone measurements.
2. Use a release-like baseline and UX-00.2's local fixtures. Separate seeding
   and network delays from measured UI work; record compilation/profile state.
3. Measure at least 30 controlled cold starts and report the distribution/p95
   to first usable local screen. State the actual measurement method.
4. Exercise history scroll, opening chat, typing, streaming, Stop, large code,
   and supported images. Capture frame distribution, frozen frames/ANRs, local
   feedback latency, and steady/peak PSS with the 10,000-message fixture.
5. Record the source plan's proposed targets: <1.5 s mid-tier cold start,
   entry-level p95 <2.5 s, ordinary local feedback <=100 ms, entry-level p95
   frame <=32 ms, no >700 ms frozen frames/ANRs, no OOM, investigate >10% PSS
   growth. Obtain an explicit decision before changing a target.
6. Preserve raw artifact links and exact scenario/build identifiers. If
   hardware or a required measurement is missing, mark this task `Blocked`;
   an emulator or a proposed protocol alone does not complete this gate.
