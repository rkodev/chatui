- Milestone: M3.5

- Order: 41

- Parallel-safe: yes, with M3.5-09.* and M3.5-10.*

- Read first: [M3.5 plan](../M3.5-rust-desktop-implementation-plan.md) sections 3.7 and 4.13; spec sections 10.9, 14.5

## Goal

Finalize the release profile for size and startup, keep a debug-symbol artifact, and record the binary-size baseline before packaging.

## Preconditions

- The workspace and UI shell exist.
- Do not break crash reporting or panic diagnostics without recording the trade-off.
- Do not commit build outputs.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- Final `[profile.release]` with:
  - `lto = "thin"` or `"fat"`;
  - `codegen-units = 1`;
  - `strip = "symbols"`;
  - `panic = "abort"` where compatible.
- A debug-symbol artifact path or documented build command.
- A release build that succeeds.
- Baseline binary size for the desktop executable.
- `docs/operations/M3.5/release-profile.md` with the settings, trade-offs, and baseline.

## Implementation steps

1. Read spec section 10.9 and the release-profile skeleton from M3.5-01.3.
2. Set the release profile. Prefer thin LTO if build time is a problem; record the choice.
3. Verify `panic = "abort"` does not break required tests, crash reporting, or the chosen UI framework. If it does, record the incompatibility and use unwind.
4. Configure a separate debug-symbol artifact. Do not rely on the stripped binary for symbolication.
5. Build the release binary:
   ```bash
   cd rust && cargo build --release -p chatui-desktop
   ```
6. Measure the executable size and record it. Do not claim installer size here; that belongs to M3.5-11.2/11.5.
7. Record the build time on the available machine.
8. Document the profile and trade-offs.

## Handoff notes

### Result (2026-11-08)

Finalized the release profile in `rust/Cargo.toml`:

```toml
[profile.release]
lto = "thin"
codegen-units = 1
strip = "symbols"
panic = "abort"

[profile.release-debug]
inherits = "release"
strip = "none"
debug = "line-tables-only"
```

- Chose thin LTO over fat: the spec allows either, and thin keeps clean build
  time practical while still enabling cross-crate optimization. Switching to
  fat is a one-line change if the installer budget later requires it.
- Kept `panic = "abort"`. It is compatible with the redacting panic hook (hooks
  run before abort), no crate uses `catch_unwind`, no test uses
  `#[should_panic]`, and the Slint shell runs normally. Tests use the dev/test
  profile, so abort does not affect the suite.
- Added a `release-debug` profile that inherits release but keeps DWARF line
  tables and symbols. Build with
  `cd rust && cargo build --profile release-debug -p chatui-desktop`; the
  artifact is `rust/target/release-debug/chatui-desktop`. It is not shipped and
  not committed (`rust/target/` is ignored).

Baseline (Linux x86_64, Intel i9-10980HK, 16 logical cores, 30 GiB, rustc
1.98.1):
