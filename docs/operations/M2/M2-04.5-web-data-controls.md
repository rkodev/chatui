## Preconditions

- M2-04.3 export and M2-04.4 import are complete.
- Settings data route exists from M2-03.4.

## Deliverables

- Storage usage display for conversations, messages, attachments, and secrets metadata.
- Clear-all-data confirmation that removes conversations, messages, attachments, and keys.
- Per-key deletion through provider management.
- Export/import entry points.
- Backup placeholder.
- Tests for confirmations, clear-all, per-key deletion, and navigation.

1. Read the data placeholder and storage repositories.

3. Add clear-all with explicit confirmation and irreversible warning.
4. Wire per-key deletion to provider management.
5. Add export/import entries.
6. Add the backup placeholder copy.
7. Add tests and manual verification.
8. Run web gates.
