# M3-06.1 - Release minification, shrinking, mapping, and keep rules

- Milestone: M3
- Status: Complete
- Order: 4
- Depends on: M3-00.1
- Parallel-safe: yes, with early M3-01/M3-03 work; not with M3-05.1 (shared app build file)
- Owns: `android/app/build.gradle.kts`, `android/app/proguard-rules.pro`, related build-logic configuration
- Read first: [M3 plan](../M3-android-depth-implementation-plan.md) sections 3.5 and 4.7; spec sections 9.5, 14.4, 16.5

## Goal

Make the release variant minified, resource-shrunk, and capable of producing a mapping artifact without breaking Room, Hilt, serialization, or Compose.

## Preconditions

- Do not add signing configuration in this task; that is M3-06.2.
- Do not disable minification to make the build pass.

## Deliverables

- Release build type with R8 minification and resource shrinking enabled.
- `proguard-rules.pro` with the required keep rules and a short comment explaining each group.
- Mapping output enabled at `android/app/build/outputs/mapping/release/mapping.txt`.
- A successful minified release build and lint run.
- A note in the handoff describing any library that needed special rules.

## Implementation steps

1. Read `android/app/build.gradle.kts` and the module dependency graph.
2. Enable release minification and shrinking:
   ```kotlin
   buildTypes {
       release {
           isMinifyEnabled = true
           isShrinkResources = true
           proguardFiles(
               getDefaultProguardFile("proguard-android-optimize.txt"),
               "proguard-rules.pro",
           )
       }
   }
   ```
   Keep the existing project conventions and formatting.
3. Create `android/app/proguard-rules.pro` with keep rules for:
   - Kotlin serialization-generated serializers used by the app;
   - Room generated implementations;
   - Hilt/Dagger generated code;
   - OkHttp/Okio only if the build reports missing classes;
   - any Compose or Tink classes that the build proves are stripped incorrectly.
4. Do not add blanket `-dontwarn` rules unless a missing optional dependency is documented.
5. Run the minified release build and lint:
   ```bash
   cd android
   ./gradlew :app:lintRelease :app:assembleRelease
   ```
6. Confirm `android/app/build/outputs/mapping/release/mapping.txt` exists and is non-empty.
7. If the minified build fails, fix the keep rules or code; do not revert to unminified release.
8. Record the actual release APK path and size in the handoff notes.

## Acceptance criteria

- [x] Release build enables minification and resource shrinking.
- [x] A release `proguard-rules.pro` exists and contains only justified rules.
- [x] `:app:assembleRelease` succeeds with minification enabled.
- [x] `mapping.txt` is produced and non-empty.
- [x] `:app:lintRelease` passes.
- [x] No destructive Room migration or fallback is introduced.

