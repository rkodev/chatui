# M0-01.1 - Provider presets and preset schema

- Status: Not started
- Parent task: M0-01
- Order: 1
- Depends on: none
- Parallel-safe: yes, with M0-01.4
- Owns: `contracts/providers.json`, `contracts/schema/provider-preset.schema.json`
- Read first: [M0 plan](../M0-foundations-implementation-plan.md) sections 3.1 and 4.2; spec sections 3.4, 5.3, 7.5, 21.3

## Goal

Create the provider preset catalog and its Draft 2020-12 schema. OpenRouter must be the only default, reference, and required preset. Every other launch preset must be present but non-blocking.

## Preconditions

- The repository has no real provider contract data yet.
- Do not create client types, provider adapters, or scripts in this task.

## Deliverables

- `contracts/providers.json` containing exactly these 14 presets:
  `openrouter`, `openai`, `anthropic`, `google`, `groq`, `mistral`, `deepseek`, `xai`, `together`, `fireworks`, `ollama`, `lmstudio`, `llamacpp`, `custom`.
- Each preset includes:
  - `id`, `label`, `kind`, `baseUrl`
  - `auth` with `type` set to `bearer`, `x-api-key`, `query-key`, or `none`
  - `keyValidation` with method and path, or `null` for local no-key presets
  - `modelDiscovery` with path, format, `public`, and `cacheTtlSeconds` where relevant
  - `browserCors` set to `supported`, `unsupported`, or `unknown`
  - `docsUrl`, `defaultModelId`
  - non-secret default headers where the protocol requires them
- OpenRouter includes:
  - role markers making it the default, reference, and required preset
  - `attributionHeaders` mapping `HTTP-Referer` to an `app.origin` placeholder and `X-Title` to an `app.name` placeholder
  - `modelDiscovery.cacheTtlSeconds` equal to `86400`
- `contracts/schema/provider-preset.schema.json`:
  - Draft 2020-12
  - `title`, `$id`, `contractVersion`
  - required fields and enums for `kind`, `auth.type`, `browserCors`
  - `additionalProperties: false` unless a field is intentionally extensible
  - explicit role fields so exactly one default and one required preset can be enforced
- Remove `contracts/.gitkeep` only if no other placeholder is still needed.

## Implementation steps

1. Read spec sections 3.4, 7.5, and 21.3.
2. Decide and document the role representation in the schema, for example `default: true`, `reference: true`, `required: true`, or a `roles` array.
3. Create the schema first and make the preset shape match it.
4. Create all 14 presets. Use placeholder labels and URLs only where the spec does not provide one; never add keys or personal data.
5. Validate that the JSON parses and IDs are unique.

## Acceptance criteria

- [ ] All 14 preset IDs exist exactly once.
- [ ] OpenRouter is the only default, reference, and required preset.
- [ ] OpenRouter has `86400` cache TTL and both attribution header mappings.
- [ ] Every preset has the required fields and valid enum values.
- [ ] No secrets, real user data, or client-specific logic exists.
- [ ] JSON parses successfully.

## Verification

```bash
jq empty contracts/providers.json contracts/schema/provider-preset.schema.json
jq -r '.[].id' contracts/providers.json | sort | uniq -d
jq 'length' contracts/providers.json
```

The duplicate-ID command must print nothing and the count must be `14`.

## Out of scope

- Fixtures, error envelopes, parity, validator, and package tooling.
- Live provider calls or CORS verification.
- Web or Android contract types.

## Handoff notes

Record the role representation and any preset whose base URL or default model is a placeholder that later milestones must confirm.
