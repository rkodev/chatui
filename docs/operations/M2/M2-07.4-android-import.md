## Goal

Implement safe Android `chatui.export` import with schema validation, merge-by-default, and no mutation on invalid input.

## Preconditions

- M2-07.3 export produces valid archives.
- Shared export fixture exists.

## Deliverables

- SAF document import and service.
- Schema, size, ID, path, and attachment-name validation.
- Merge-by-default and optional replace.
- Transactional application of valid archives.
- No mutation on invalid input.
- Preservation of IDs, order, snapshots, and attachment references.
- Tests for round trip and invalid inputs.

## Implementation steps

1. Read the export schema, fixture, and Room repositories.
2. Add input size and schema validation before writes.
3. Validate relationships and attachment names.
4. Implement transactional merge.
5. Add explicit replace mode with confirmation.
6. Restore attachments.
7. Add tests.
8. Run Android gates.

## Acceptance criteria

- [ ] Valid archives import and round trip.
- [ ] Merge is default; replace is explicit.
- [ ] Invalid imports do not mutate data.
- [ ] Unsafe paths/names are rejected.
- [ ] IDs, order, snapshots, and attachments are preserved.
- [ ] Android gates pass.
