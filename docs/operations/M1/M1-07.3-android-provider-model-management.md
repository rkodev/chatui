## Goal

Deliver Android provider management and the model picker/manage-models surfaces, including defaults and curated routing controls.

## Preconditions

- Onboarding can create an OpenRouter provider.
- Services can validate, refresh, and persist models.

## Deliverables

- Provider list/detail with key label, usage, limit, free tier, rate-limit note, CORS status, enabled toggle, key rotation/removal.
- Provider-docs link from preset `docsUrl`.
- Model picker bottom sheet with search, provider groups, pinned first, capability chips, context, modalities, price per million, free badge, unavailable warning, manual add, and details.
- Manage models: pin/hide, manual add, refresh.
- Global default provider/model and per-conversation override with immediate persistence.
- Assistant-message snapshots in metadata.
- Minimal curated routing controls (`allow_fallbacks`, `sort`, `data_collection: "deny"`) and routing summary.
- Tests for model pricing/free badge, switching, defaults, and routing state.

## Implementation steps

1. Read the provider placeholder and service APIs.
2. Build provider list/detail ViewModels and composables.
3. Render `/key` metadata without exposing the secret.
4. Build the model picker bottom sheet and search/grouping selectors.
5. Implement pin/hide/manual add through the model repository.
6. Implement global defaults and per-conversation override.
7. Add routing controls and store values in `conversation.params.extra.openrouter.provider`.
8. Show a routing summary only when active.
9. Add tests and run the Android gate.

## Acceptance criteria

- [ ] Provider details show key metadata and CORS status.
- [ ] Key rotation/removal and enabled toggle work.
- [ ] Model picker shows search, grouping, chips, context, modalities, price, and free badge.
- [ ] Pin/hide/manual add persist.
- [ ] Model switch persists immediately and applies to the next send.
- [ ] Assistant messages keep provider/model snapshots.
- [ ] Routing controls serialize correctly.
- [ ] Other providers and custom creation remain unavailable.
- [ ] Android gate passes.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```

## Out of scope

- Full parameter sheet and advanced JSON editor.
- Attachments and capability confirmations beyond unavailable-model warnings.
- Additional providers.
- Search/export/import.
