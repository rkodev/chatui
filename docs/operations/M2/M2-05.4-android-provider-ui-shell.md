## Goal

Expose the full provider management flow from the Android app shell and update the UI for all enabled presets and Custom providers.

## Preconditions

- M2-05.3 provider services are complete.
- Existing provider screens and ViewModels are available.

## Deliverables

- Provider route in `ShellNavHost` replacing `ProvidersPlaceholder`.
- Provider list/detail support for enabled presets and Custom providers.
- Navigation from chat model chip and settings to provider management.
- Provider tests and navigation tests.

## Implementation steps

1. Read `ShellNavHost`, `ProvidersPlaceholder`, and provider routes.
2. Replace the placeholder with the real provider list/detail routes.
3. Update provider list/detail for multiple presets and Custom.
4. Wire chat and settings entry points.
5. Add navigation tests.
6. Run Android gates.

## Acceptance criteria

- [ ] Provider management is reachable from the shell.
- [ ] Chat and settings entry points open provider management.
- [ ] Enabled presets and Custom providers are visible.
- [ ] OpenRouter provider flow still works.
- [ ] Placeholder is no longer routed.
- [ ] Android gates pass.
