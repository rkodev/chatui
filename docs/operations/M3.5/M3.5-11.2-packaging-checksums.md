# M3.5-11.2 - Cross-platform packaging and checksums

- Milestone: M3.5
- Status: Complete
- Order: 42
- Depends on: M3.5-11.1, M3.5-08.1
- Parallel-safe: yes, with M3.5-09.* and M3.5-10.*
- Owns: `rust/dist/`, packaging configuration, packaging scripts, `Makefile` (`rust-package` target only), `docs/operations/M3.5/packaging.md`
- Read first: [M3.5 plan](../M3.5-rust-desktop-implementation-plan.md) sections 3.7 and 4.13; spec sections 10.10, 14.5

## Goal

Produce installable desktop artifacts for Windows, macOS, and Linux with checksums, using a reproducible `cargo-dist` or equivalent pipeline.

## Preconditions

- The release profile and shell exist.
- Do not commit installers, signing keys, or generated build outputs.
- Do not bundle a browser engine.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- Packaging configuration using `cargo-dist` or an equivalent pipeline.
- Required formats:
  - Windows MSI or portable zip;
  - macOS signed/notarized DMG or app bundle;
  - Linux AppImage and/or `.deb`/`.rpm`.
- Checksums for every artifact.
- A packaging document with commands, prerequisites, and output paths.
- At least one artifact built locally on the available OS. Cross-OS artifacts may be built in CI in M3.5-11.4.

## Implementation steps

1. Read spec sections 10.10 and 14.5.
2. Evaluate `cargo-dist` or the chosen equivalent in M3.5-00.2. Confirm it supports the required formats or add a wrapper.
3. Configure the app metadata: name, version, description, license, authors, icons if required.
4. Configure installers per target. Keep Windows, macOS, and Linux builds feature-complete but avoid platform-specific bloat.
5. Build the artifact for the available OS and record the command.
6. Generate SHA-256 checksums for every artifact.
7. Document the cross-platform build commands and expected artifact names.
8. Record any format that cannot be produced with the chosen tool as a precise blocker.
9. Do not package the updater manifests yet; M3.5-11.3 owns signing them.

## Acceptance criteria

- [x] Packaging configuration exists and builds at least one artifact locally.
- [x] Windows, macOS, and Linux formats are configured.
- [x] Artifacts have SHA-256 checksums.
- [x] The packaging document lists commands and output paths.
- [x] No installer or signing material is committed.
- [x] No browser engine is bundled.
- [x] Unsupported formats are recorded as blockers.
- [x] The artifact launches on the available OS.

## Verification

```bash
make rust-package
ls -lh rust/dist/
sha256sum rust/dist/* 2>/dev/null || true
```

On the available OS, install or run the artifact and record the result.

## Out of scope

- Auto-update manifests and signatures (M3.5-11.3).
- CI release automation (M3.5-11.4).
- Performance and installer-size evidence (M3.5-11.5).

## Handoff notes

### Result (2026-11-08)

Selected an equivalent packaging pipeline instead of `cargo-dist`. `cargo-dist`
is not installed here and its default artifact set does not cover the full
required matrix (DMG, AppImage, `.deb`, `.rpm`) without wrappers. The pipeline
is `rust/packaging/package.py`, configured by `rust/packaging/package.toml`,
and invoked by `make rust-package`.

Decisions and notes:

- The version is read from `rust/apps/desktop/Cargo.toml`; it is not duplicated
  in the packaging config.
- The license metadata is `Proprietary` as a placeholder because the repository
  has no `LICENSE` file. This is not a product decision; replace it when the
  project license is confirmed.
- The Linux icon is a placeholder SVG. macOS `.icns` and Windows `.ico`
  generation is a follow-up if native icons are required.
- AppImage and RPM are not produced (`appimagetool`/`rpmbuild` absent); `.deb`
  satisfies the Linux requirement. MSI is not produced; the portable zip
  satisfies the Windows requirement.
- macOS signing/notarization hooks are wired through `APPLE_SIGNING_IDENTITY`
  and `APPLE_NOTARY_PROFILE`; no credentials are committed. Windows Authenticode
  signing is not implemented (B-04).
- No updater manifests are packaged; M3.5-11.3 owns them.
- No browser engine is bundled; the pipeline copies only the Slint binary,
  desktop entry, SVG icon, and README.
- `rust/dist/` and `rust/target/` are ignored by git; no installers or build
  outputs were committed.
- `docs/operations/M3.5/tooling.md` still says `rust-package` fails until
  M3.5-11.2. That page is outside this task's scope; update it in a follow-up
  documentation pass.

Cross-OS blockers: B-01 (macOS runner), B-02 (Windows runner), B-03 (Apple
signing/notarization credentials), B-04 (Windows Authenticode certificate).
These are external environment/credential blockers; the formats are configured
and the Linux artifact is built and launched locally.

Documented commands, prerequisites, output paths, checksums, and blockers in
`docs/operations/M3.5/packaging.md`.
