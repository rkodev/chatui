## Goal

Finish the generic UI primitives and prove the web foundation launches to a themed shell. This is the final web gate before CI wiring.

## Preconditions

- Router, theme provider, tokens, storage, and secrets are implemented.
- Do not add feature screens.

## Deliverables

- Generic primitives:
  - `Button`
  - `Dialog`
  - `Menu`
  - `Tooltip`
  - `Toast` and a toast provider wired to the shell store
  - shared focus and disabled states
- Use Radix UI primitives for dialogs, menus, and tooltips where appropriate. Add `lucide-react` only if an icon is needed by the primitives.
- Primitive tests with Testing Library:
  - keyboard activation where applicable
  - dialog open/close and focus behavior
  - menu open/select behavior
  - tooltip accessible naming
  - toast add/dismiss
- Shell smoke tests:
  - app renders with valid config
  - invalid config shows a visible diagnostic
  - theme switching changes the theme attribute
  - required routes render placeholders
- Remove any placeholder files superseded by real files.
- Run the complete web gate and record results in the handoff notes.

## Implementation steps

1. Add only the dependencies needed by the primitives.
2. Implement primitives one at a time with focused tests.
3. Wire the toast provider into the shell.
4. Add shell smoke tests.
5. Run all web commands.
6. Launch the dev server and confirm the themed shell renders, then stop it.
7. Capture evidence for the M0 exit gate.

## Acceptance criteria

- [x] Button, Dialog, Menu, Tooltip, and Toast exist as generic primitives.
- [x] Primitive tests pass and cover keyboard/accessibility basics.
- [x] The app launches to a themed shell with history routing.
- [x] Invalid config is visible, not silent.
- [x] Theme switching works.
- [x] No provider adapter, onboarding, chat, sidebar, search, export/import UI, PWA, or service worker exists.
- [x] `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build` pass.

## Verification

```bash
cd web && pnpm lint
cd web && pnpm typecheck
cd web && pnpm test
cd web && pnpm build
cd web && pnpm dev
```

For the last command, confirm the shell renders and then stop the server. Do not leave a background process running.

## Out of scope

- Any feature UI, E2E/Playwright, axe audit, PWA, deployment headers, or production static-host fallback.
- Provider or model picker components.

### Decisions

- `web/src/app/providers.tsx` was updated to mount `ToastProvider`. The task explicitly requires wiring the toast provider into the shell, and the existing comment in that file reserved the change for M0-03.3.
- `web/src/ui/.gitkeep` was removed because the `ui` directory now contains real files.
- Radix primitives own focus trapping, focus restoration, roving menu focus, and tooltip `aria-describedby`; the shared CSS supplies focus-visible and disabled states.
- Test setup now provides inert `ResizeObserver`, pointer-capture, `scrollIntoView`, and `scrollTo` shims so Radix primitives run under jsdom.
