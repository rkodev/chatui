## Goal

Implement the native Google Gemini adapter with `alt=sse`, system instructions, inline images, generation config, usage metadata, and finish-reason mapping.

## Preconditions

- The OpenAI-compatible preset adapter and shared transport exist.
- Do not put the API key in the query string.
- Do not add Gemini-specific logic outside the adapter.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- Gemini request serialization:
  - `systemInstruction`;
  - `contents` with `model` role for assistant turns;
  - `inlineData` for images;
  - `generationConfig` with sampling controls;
  - `stopSequences`.
- Streaming endpoint selection with `alt=sse` and `x-goog-api-key`.
- Streaming normalization:
  - `candidates[0].content.parts[].text` -> `text-delta`;
  - `usageMetadata` -> usage;
  - finish reasons: `STOP` -> `stop`, `MAX_TOKENS` -> `length`, `SAFETY`/`RECITATION` -> `content_filter`, others -> `unknown`.
- Gemini `/models` mapping.
- Tests against Gemini request, stream, finish-reason, error, and catalog vectors.

## Implementation steps

1. Read `web/src/providers/gemini.ts` and the Gemini fixtures.
2. Implement headers with `x-goog-api-key`. Never put the key in the URL.
3. Serialize the system prompt as `systemInstruction`.
4. Convert normalized messages to `contents`; assistant messages use `role: "model"`.
5. Convert images to `inlineData` with `mimeType` and base64 data.
6. Put sampling controls under `generationConfig` and map `stop` to `stopSequences`.
7. Build the streaming URL with `:streamGenerateContent?alt=sse`.
8. Normalize text deltas, usage metadata, and finish reasons.
9. Implement Gemini `/models` mapping.
10. Add tests for text, finish reasons, usage, auth/context/permission errors, 429, and attachments.
11. Run the shared conformance suite.

## Acceptance criteria

- [ ] Gemini request bodies match the shared vectors.
- [ ] The key travels only in `x-goog-api-key`.
- [ ] System instructions, contents, images, generation config, and stop sequences are correct.
- [ ] Finish reasons match the required mapping.
- [ ] Usage metadata maps correctly.
- [ ] Errors normalize to shared `ChatError`.
- [ ] Model discovery maps into the shared `Model` shape.
- [ ] Tests pass.
