## Goal

Add a CI workflow that runs the Android lint, unit-test, and debug-assemble gates on pull requests.

## Preconditions

- `android/gradlew` is committed and executable.
- The Android gates pass locally.
- No release signing material is committed.

## Deliverables

- `.github/workflows/android.yml`:
  - triggers on pull requests and pushes to the default branch
  - JDK 21 setup with a stable distribution
  - Android SDK setup using the runner's installed SDK or an explicit setup action
  - Gradle dependency and wrapper caching
  - `./gradlew lintDebug testDebugUnitTest assembleDebug` from `android/`
  - upload the debug APK artifact with bounded retention
  - `permissions: contents: read`
  - concurrency group per branch/PR with cancel-in-progress
  - bounded timeout
- Use `gradlew` from the repository, not a system Gradle.
- No signing secrets, Play Store publishing, emulator matrix, or release build.
- Do not echo environment secrets.

## Implementation steps

1. Write the workflow with the JDK and caching steps.
2. Confirm the Gradle wrapper path and working directory are correct.
3. Confirm the SDK/compile version matches the repository configuration.
4. Push a draft PR or use the repository's CI mechanism and run the workflow.
5. Fix CI-only failures such as a missing SDK component, a non-executable wrapper, or an incorrect cache path.
6. Record the run result in the handoff notes.

## Acceptance criteria

- [ ] The workflow file exists and parses as YAML.
- [ ] JDK and Android SDK setup are explicit.
- [ ] Gradle caches are configured.
- [ ] `lintDebug`, `testDebugUnitTest`, and `assembleDebug` run and pass.
- [ ] The debug APK is uploaded as an artifact with bounded retention.
- [ ] Permissions, concurrency, and timeout are configured.
- [ ] No signing or publishing material is referenced.
- [ ] The workflow passes in CI.

## Verification

```bash
make android-lint && make android-test && make android-assemble
git status --short
```

Plus a successful Android workflow run.

## Out of scope

- Release signing, Play Store, emulator instrumented tests, baseline profiles, and Rust.

## Handoff notes

Record the workflow run link, the JDK/SDK versions used by CI, and any difference from the local Android toolchain.
