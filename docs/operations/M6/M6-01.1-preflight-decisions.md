## Goal

feature-flag, and privacy-review decisions that every later task depends on. No
templates or documentation should be finalized before these decisions exist.

## Preconditions

- M4 and M5 are complete and their verification records exist.

  inventing an answer.

  - `DEC-M6-01`: M6 authorization and confirmation that this is a
    hosting/documentation milestone, not a backend build.
  - `DEC-M6-02`: repository versus external-operator boundary. The repository
    owns static artifacts, schemas, templates, docs, and evidence; the external
