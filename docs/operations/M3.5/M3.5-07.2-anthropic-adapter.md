## Goal

Implement the native Anthropic Messages adapter with thinking/text separation, base64 images, system prompts, usage, and error mapping.

## Preconditions

- The OpenAI-compatible preset adapter and shared transport exist.
- Do not send the web-only `anthropic-dangerous-direct-browser-access` header unless the contract explicitly requires it on desktop.
- Do not add Anthropic-specific logic outside the adapter.
- Do not modify `web/`, `android/`, or `contracts/`.

## Deliverables

- Anthropic request serialization:
  - top-level `system`;
  - text and base64 image blocks;
  - `max_tokens` always emitted, default 1024 when unset;
  - `stop_sequences`;
  - `anthropic-version`.
- Anthropic SSE normalization:
  - `message_start` -> `start` and initial usage;
  - `content_block_start` text/thinking;
  - `content_block_delta` text/thinking deltas;
  - `message_delta` output usage and stop reason;
  - `message_stop` -> finish;
  - `error` -> normalized error.
- Reasoning and answer text kept separate.
- Anthropic model discovery mapping.
- Tests against Anthropic request, stream, thinking, error, and catalog vectors.

## Implementation steps

1. Read `web/src/providers/anthropic.ts` and the Anthropic fixtures.
2. Implement headers:
   - `x-api-key`;
   - `anthropic-version: 2023-06-01`;
   - `content-type: application/json`;
   - `Accept: text/event-stream`.
3. Serialize normalized messages into Anthropic `messages` with text and image blocks. Put the system prompt in the top-level `system` field.
4. Always emit `max_tokens`, using 1024 when unset.
5. Map `stop` to `stop_sequences`.
6. Implement SSE event handling. Map thinking deltas to `reasoning-delta` and text deltas to `text-delta`. Never concatenate them.
7. Merge initial and final usage correctly.
8. Map stop reasons and errors to the shared types.
9. Implement Anthropic `/models` mapping.
10. Add tests for text, thinking/text separation, usage ordering, auth errors, 429, 404, context errors, and attachments.
11. Run the shared conformance suite.

## Acceptance criteria

- [ ] Anthropic request bodies match the shared vectors.
- [ ] System prompt and generation controls are correct.
- [ ] Thinking and text deltas remain separate.
- [ ] Usage and finish reasons map correctly.
- [ ] Errors normalize to shared `ChatError`.
- [ ] Model discovery maps into the shared `Model` shape.
- [ ] No web-only header is sent unless contract-mandated.
- [ ] No secrets are logged.
- [ ] Tests pass.
