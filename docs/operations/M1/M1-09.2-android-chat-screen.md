## Goal

Render the Android chat screen and composer on top of the chat ViewModel, including streaming presentation, states, and accessibility.

## Preconditions

- Chat ViewModel/runner is complete.
- Do not add Markdown or message actions in this task beyond extension points.

## Deliverables

- Chat screen with `LazyColumn`, stable keys and content types, and older-message paging.
- Isolated streaming message so token updates do not recompose history.
- Message item with role layout, metadata, cancelled/interrupted state, and inline error card.
- Chat states: no provider, empty, sending, streaming, complete, error, model unavailable.
- Composer with auto-grow, send-key behavior, per-conversation drafts, send/stop, disabled states, and text preservation.
- Conditional auto-scroll and live-region/semantics announcements for start, complete, and error.
- Composable/unit tests for states, composer behavior, and streaming isolation.

## Implementation steps

1. Read the chat placeholder, shell navigation, and design tokens.
2. Build the screen scaffold and message list.
3. Build `MessageItem` with metadata and states.
4. Subscribe only the streaming item to streaming state.
5. Build the composer with `TextField`/`BasicTextField` auto-grow and send-key handling.
6. Add disabled logic for empty, streaming, offline, no provider, and model unavailable.
7. Add auto-scroll when near the bottom.
8. Add semantics/live announcements for start, complete, and error.
9. Add tests and run the Android gate.

## Acceptance criteria

- [ ] Message list uses stable keys and paginates older messages.
- [ ] Streaming token updates do not recompose history.
- [ ] Empty, no-provider, streaming, complete, error, cancelled, and unavailable states exist.
- [ ] Composer follows send-key settings, preserves drafts, and disables correctly.
- [ ] Stop cancels the active stream.
- [ ] Accessibility announces start/complete/error, not tokens.
- [ ] Android gate passes.

## Verification

```bash
make android-lint && make android-test && make android-assemble
```
