## Handoff notes

- Usage calculation: `DataControlsService.getUsage()` in `web/src/features/settings/dataControlsService.ts` counts conversations, messages, attachments, stored keys, providers, and models. Conversation/message/provider/model bytes are estimated from `JSON.stringify` record sizes. Attachment bytes come from attachment metadata `size`, deduplicated by SHA-256; the `attachmentBlobs` store and OPFS are never read. Secret bytes are the stored ciphertext length, excluding the device key, passphrase salt, and passphrase check records. `DataUsagePanel` renders the table and `formatBytes()` formats sizes.
- Clear-all scope: `DataControlsService.clearAll()` clears `conversations`, `messages`, `attachments`, `providers`, `models`, `secrets`, and `syncQueue` in one IndexedDB transaction, then calls `AttachmentStore.cleanupOrphans(new Set())` to remove OPFS files and IndexedDB fallback blobs. Appearance/chat preferences (`settings`) and `backupConfig` are intentionally kept so the app remains usable after a reset. The UI requires typing `DELETE ALL DATA` before the button enables and shows an irreversible warning.
- Per-key deletion path: `DataKeysPanel` lists providers with stored keys and calls `DataControlsService.removeProviderKey()`, which delegates to `ProviderService.removeKey()` from provider management. That deletes the secret records and clears cached key metadata while keeping the provider and its models. The panel links to `/settings/providers` for full provider management.
- Entry points: `/settings/data` now renders `DataUsagePanel`, `DataKeysPanel`, `DataClearPanel`, `DataExportPanel`, and `DataImportPanel` from one IndexedDB connection. Import success and key deletion bump a refresh key so usage reloads. `BackupSettingsScreen` remains a reachable placeholder with no controls.
- Tests: `dataControlsService.test.ts` covers usage counts, metadata-only attachment sizing, SHA-256 deduplication, clear-all across stores and attachment bytes, key listing, and real `ProviderService.removeKey` metadata cleanup. `DataControlsPanels.test.tsx` covers byte formatting, usage rendering, confirmation gating, per-key two-step removal, data-screen entry points, and the backup placeholder.
