## Goal

Implement native Ollama NDJSON chat and `/api/tags` discovery on Android, with the OpenAI-compatible path as fallback.

## Preconditions

- M2-00.1 Ollama vectors exist.
- M2-05.1 generic transport is available.

## Deliverables

- Native `/api/chat` NDJSON streaming.
- `/api/tags` discovery and model mapping.
- OpenAI-compatible fallback.
- Usage, finish, error, retry, and cancellation mapping.
- Local cleartext warning/documentation where applicable.
- Fixture tests and adapter registration.

## Implementation steps

1. Read the Ollama fixtures.
2. Implement a bounded NDJSON reader with final flush.
3. Map `done`, `done_reason`, and eval counts.
4. Implement tags discovery.
5. Implement fallback selection.
6. Add tests for NDJSON, discovery, fallback, errors, and cancellation.
7. Register the adapter.
8. Run Android gates.

## Acceptance criteria

- [ ] NDJSON streaming completes and records usage.
- [ ] Tags discovery maps models correctly.
- [ ] Fallback selection is deterministic.
- [ ] Errors, retry, and cancellation follow the shared contract.
- [ ] Local cleartext behavior is documented.
- [ ] Android gates pass.
