## Goal

Implement the Material 3 design system so the app can render a themed shell with the shared semantic tokens.

## Preconditions

- The `core:designsystem` module exists and builds.
- No feature UI is allowed.

## Deliverables

- Material 3 color schemes for light and dark themes.
- System theme support via `isSystemInDarkTheme()` or an equivalent setting.
- Semantic tokens from spec 11.12 mapped to Compose values:
  - background, surface, raised surface, user bubble, code background
  - foreground primary, secondary, muted, on-accent
  - accent, accent-hover, subtle and strong borders
  - danger, warning, success
  - spacing, radii, body/code typography, heading styles
- `Dimens` and `Typography` objects with semantic names matching the web token names.
- Density support for comfortable and compact modes.
- Reduced-motion support where Compose exposes animation duration or motion preferences.
- A `ChatUiTheme` composable that accepts theme mode and density.
- Tests or compile-time checks for theme construction and token availability.

## Implementation steps

1. Translate the token list into Compose objects.
2. Build light and dark color schemes.
3. Add typography and dimens.
4. Add the theme composable and density handling.
5. Add reduced-motion handling.
6. Run the module build and Android gates.

## Handoff notes

- Token mapping: dotted spec names map to camel-case Compose properties: `color.bg.canvas` -> `ChatUiColors.bgCanvas`, `space.1` -> `Dimens.space1`, `radius.sm` -> `Dimens.radiusSm`, `font.body.size` -> `Typography.bodySize`. Heading tokens are `headingFamily`, `headingSize`, `headingSize1` through `headingSize3`, `headingLineHeight`, `headingLineHeight1` through `headingLineHeight3`, and `headingWeight`. Chat text tokens are `chatSizeSm/Md/Lg` and `chatLineHeightSm/Md/Lg` with `Typography.chatStyle(ChatFontSize)`.
- Theme contract: `ChatUiTheme(themeMode, density, reducedMotion, content)` resolves `Theme.SYSTEM` through `isSystemInDarkTheme()`, selects `LightColors`/`DarkColors`, and provides `LocalChatUiColors`, `LocalDimens`, `LocalChatUiTypography`, `LocalChatUiMotion`, and `LocalReducedMotion`. `Density.COMFORTABLE` and `Density.COMPACT` select `ComfortableDimens` and `CompactDimens`.
- Material 3 color-role compromise for M4 review: Material 3 has no roles for user bubble, code background, accent-hover, or success. `bgUserBubble` maps to `primaryContainer`, `bgCode` to `surfaceVariant`, `accentHover` to `secondary`, `warning` to `tertiary`, and `success` remains available only through `ChatUiColors`. `bgSurfaceRaised` maps to `surfaceContainer`, `surfaceContainerHigh`, and `surfaceContainerHighest`. Review these mappings when feature components start consuming Material roles.
- Reduced motion: Compose 1.12 exposes `MotionDurationScale` as a coroutine context element rather than a public composition local, so `rememberReducedMotion()` reads and observes `Settings.Global.ANIMATOR_DURATION_SCALE`. A zero scale selects `ChatUiMotion.Reduced`, which zeroes `fastMillis` and `normalMillis`. `ChatUiTheme` accepts an explicit `reducedMotion` override for previews and tests.
- Chat font size: the design system exposes chat typography tokens and `Typography.chatStyle`, but `ChatUiTheme` intentionally does not accept a chat font-size parameter in this task. The settings/shell task can provide the persisted `ChatFontSize` to feature text.
- M4 review: dynamic color, screenshot tests, and the full accessibility audit remain out of scope.
