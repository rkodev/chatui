# M5-03.2 - Android S3-compatible adapter and conditional writes

- Milestone: M5
- Status: Not started
- Order: 10
- Depends on: M5-02.2
- Parallel-safe: yes, with `M5-03.1` and `M5-03.3`
- Owns: `android/core/backup/`, `android/core/network/`
- Read first: [M5 plan](../M5-backup-and-sync-implementation-plan.md) sections 3.4 and 5.3; spec section 13.6; `contracts/schema/backup-envelope.schema.json`

## Goal

Implement the S3-compatible storage backend on Android with SigV4, conditional
writes, a connectivity test, and typed errors. The adapter must only ever
receive encrypted bytes.

## Preconditions

- `M5-02.2` is `Complete` and the manifest/payload code exists.
- `android/core/network` already provides OkHttp. Reuse it.
- Do not add a cloud SDK or a server proxy.

## Deliverables

- `android/core/backup/.../storage/StorageAdapter.kt`:
  - `testConnection`, `getObject`, `putObject`, `headObject`, `deleteObject`,
    `listObjects`.
  - `StorageObject`, `StorageError` with typed codes.
- `android/core/backup/.../storage/SigV4Signer.kt`:
  - Canonical request, string to sign, signing key, `Authorization` header.
  - Support `GET`, `PUT`, `HEAD`, `DELETE`.
- `android/core/backup/.../storage/S3StorageAdapter.kt`:
  - Path-style and virtual-hosted-style URLs.
  - `If-Match`/`If-None-Match` conditional writes.
  - ETag capture and return.
  - Conservative eventual-consistency handling.
- Tests:
  - SigV4 known-answer test.
  - Adapter tests with `MockWebServer`.
  - Conditional write conflict returns `conflict`.
  - Connectivity test returns typed errors.
  - No plaintext is passed to the adapter in tests.

## Implementation steps

1. Read the envelope codec, manifest/payload code, and `android/core/network`.
2. Define the `StorageAdapter` interface and error types.
3. Implement `SigV4Signer` with `javax.crypto.Mac` HMAC-SHA256 and
   `MessageDigest` SHA-256.
4. Implement `S3StorageAdapter` with OkHttp:
   - Build the URL from endpoint, bucket, and key.
   - Sign every request.
   - Send `If-Match` on manifest rewrite and `If-None-Match: *` on create.
   - Parse `ETag` and map HTTP status to typed errors.
5. Implement `testConnection` with a `HEAD` on the bucket or a small probe
   object. Do not write plaintext.
6. Add tests with `MockWebServer`. Use synthetic encrypted bytes only.
7. Run the Android gates.

## Acceptance criteria

- [ ] `StorageAdapter` and typed errors exist.
- [ ] SigV4 signing passes a known-answer test.
- [ ] GET/PUT/HEAD/DELETE work against `MockWebServer`.
- [ ] Conditional writes use `If-Match`/`If-None-Match` and surface conflicts.
- [ ] ETags are captured and returned.
- [ ] Connectivity test returns typed errors and writes no plaintext.
- [ ] No cloud SDK or server proxy is added.
- [ ] The adapter only receives encrypted bytes.
