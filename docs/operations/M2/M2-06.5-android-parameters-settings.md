## Goal

Add per-conversation parameters, a full-height conversation settings sheet, and the Android settings screens with behavior wiring.

## Preconditions

- M2-00.2 request vectors and extra namespace rule exist.
- M2-05.3 models expose supported parameters.

## Deliverables

- Conversation settings sheet: model, system prompt, temperature, top P, max output tokens, stop, reasoning effort, streaming toggle, routing summary, export, delete.
- Provider extras with validation and protected-field rejection.
- Unsupported-parameter note.
- Settings screens: appearance, chat defaults, providers, data entry, backup placeholder, about/privacy.
- Behavior wiring for defaults, send key, token usage, remote images, last active.
- Shell settings route replacing `SettingsPlaceholder`.
- Tests for persistence, validation, and navigation.

## Implementation steps

1. Read `ChatParams`, `DefaultChatContextResolver`, and settings placeholders.
2. Add the conversation settings sheet and ViewModel actions.
3. Add extras validation and protected-field checks.
4. Add the settings screens and navigation.
5. Wire every behavior-affecting setting.
6. Add tests and replace the placeholder route.
7. Run Android gates.

## Acceptance criteria

- [ ] Per-conversation prompt/params persist and affect requests.
- [ ] Unsupported params are explained.
- [ ] Protected fields cannot be overridden.
- [ ] Settings screens are reachable and persist.
- [ ] Settings affect behavior.
- [ ] Conversation settings sheet works.
- [ ] Android gates pass.
